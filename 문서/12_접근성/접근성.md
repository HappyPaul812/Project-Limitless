# 접근성

## 상태

🟡 초안

## 목표

모든 플레이어가 가능한 한 같은 경험을 할 수 있도록 설계한다.

## 입력

- 마우스만으로 플레이 가능
- 키보드만으로 플레이 가능
- 게임패드 지원

## UI

- 글자 크기 조절
- UI 확대
- 색약 대응
- 명확한 아이콘

## 게임플레이

- 턴제 전투
- 싱글플레이 전투의 행동 선택은 입력 시간 제한 없음
- 멀티플레이 전투는 동시 입력을 사용하며 기본 45초 제한, 남은 시간 10초 경고, 시간초과 시 방어 적용
- 멀티플레이 시간 경고는 색상만으로 전달하지 않음
- 자동 저장
- 반복 입력 최소화
