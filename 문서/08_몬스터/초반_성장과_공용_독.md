# 초반 성장과 공용 독

## 확정 성장 규칙 (2026-09-07)

- 최고 레벨은 기존 `CharacterGrowthCalculator.MaxLevel = 50` 한 곳에서 관리한다.
- `ExperienceProgression.RequiredExp(L) = 100 + 25×(L-1) + 5×(L-1)²`. Lv1~49에 적용하며 Lv50은 다음 필요 EXP가 없으므로 API는 0을 반환한다.
- Lv1→2: 100, Lv2→3: 130, Lv3→4: 170, Lv4→5: 220, Lv5→6: 280.
- `CurrentExperience`는 현재 레벨에서 진행 중인 경험치이며 평생 누적 EXP가 아니다. 레벨업 비용을 뺀 나머지는 다음 레벨로 이월한다. 충분한 보상은 여러 레벨을 연속 상승시키며 Lv50을 넘지 않는다.
- 예: Lv4의 EXP 200 + 보상 50 → Lv5 EXP 30/280. Lv1에서 400 EXP → Lv4 EXP 0/220.
- 만렙은 다음 진행 구간이 없어 CurrentExperience를 0으로 정규화한다. 획득 보상 자체는 결과창에 표시한다.
- 기존 Level/JobId 기반 능력치 공식을 그대로 사용한다. 다음 Battle 참가자 생성은 갱신된 Level로 HP/MP·공격·방어·능력치를 계산한다. 종료한 전투의 Combatant는 계속 성장시켜 재활용하지 않는다.
- **레벨업 HP/MP 완전 회복 여부는 미확정**이다. 별도 회복 처리를 추가하지 않았다. 기존 구조는 매 전투 참가자를 새로 만들며 `CurrentHp=MaxHp`, `CurrentMp=MaxMp`로 시작한다. 전투 간 HP/MP 지속 저장은 이번 범위가 아니다.

## 이름색과 EXP의 공통 판정

`ExperienceProgression.GetCategory`가 몬스터 레벨에서 플레이어 레벨을 뺀 차이를 한 번 정의하며, 이름색과 배율 모두 이 enum을 읽는다.

| 몬스터-플레이어 레벨 차이 | 분류/몬스터 이름색 | EXP 배율 |
|---|---|---|
| -7 이하 | 회색 | 0% |
| -6~-4 | 녹색 | 50% |
| -3~+3 | 노란색 | 100% |
| +4~+6 | 주황색 | 125% |
| +7 이상 | 빨간색 | 150% |

- 플레이어/NPC 흰색 이름표는 유지한다. 몬스터는 흰색을 사용하지 않는다.
- 월드 몬스터 이름표는 `Lv.n 이름`으로 레벨도 명시한다. 색만으로 정보를 전달하지 않는다.
- LateUpdate에서 플레이어/몬스터 레벨 변화 시 색과 레벨을 갱신한다.
- 오래된 저레벨 몬스터 반복 사냥으로만 성장하지 않도록 회색 보상은 0이다.
- 각 몬스터 Base EXP에 배율을 곱한 뒤 **가장 가까운 정수, .5는 위로 반올림**한다. `long` 정수 퍼센트 계산 후 몬스터별 값을 합산한다. float 오차 및 큰 값의 중간 곱셈 오버플로를 피한다.
- 한 승리의 모든 몬스터 배율은 EXP를 적용하기 전 플레이어 Level 기준이다. 합산 중 레벨업해 뒤쪽 몬스터 보상이 바뀌지 않는다.

## 몬스터 데이터와 조우

| 종류 | Level | Base EXP | MaxHP | Attack | 조우 전열 2 / 후열 1 |
|---|---:|---:|---:|---:|---|
| 초원 슬라임 | 1 | 8 | 60 | 10 | 슬라임 2 / 슬라임 1 |
| 독침벌 | 2 | 12 | 70 | 12 | 슬라임 2 / 독침벌 1 |
| 숲거미 | 3 | 16 | 80 | 14 | 독침벌 2 / 숲거미 1 |
| 맹독뱀 | 4 | 20 | 95 | 16 | 숲거미 2 / 맹독뱀 1 |

`MonsterDefinition`에 MonsterLevel, BaseExperience, MaxHp, EncounterSupportMonster를 보관한다. 기존 BattleAttackPercent 100/120/140/160은 유지하며 숲거미의 별도 광역 독액 분사 20도 유지한다. EncounterSupportMonster가 없으면 같은 종류를 사용한다. 새 몬스터 추가 시 직전 최강 종류를 데이터로 연결하며 이름 문자열 분기를 추가하지 않는다.

노란색 배율일 때 각 조우 보상은 24/28/40/52 EXP다. 실제 전투불능 적 Combatant마다 지급하므로 같은 정의의 벌 두 마리도 각각 계산한다. 목록의 동일 Combatant 참조 중복은 한 번만 계산한다.

- Field_01 권장 Lv1~3, Field_02 권장 Lv3~5. 초반 약 4~5전투/레벨이 목표이며 수치를 임의로 자동 보정하지 않는다.
- Field_02의 기존 거미 4개 유지, 뱀 **2개** 추가: `venom_snake_01=(-2.2,0.3)`, `venom_snake_02=(1.4,-3.8)`, 활동 반경 각각 1.1, 리스폰 30초.
- 기존 나무/바위·거미 위치와 북쪽 안전 원 `(0,5.65), r=2.2`, WorldBounds `(21,15)`를 고려했다. 뱀 활동 원 전체가 Bounds와 안전지대 조건을 만족하고 기존 스폰 활동 원과 겹치지 않는다. Scene Asset을 재생성하지 않는다.
- 필드 접촉 스폰 제거/리스폰과 전투의 몬스터별 EXP는 별개다. 승리로 접촉 스폰 하나만 제거하고 도망은 제거하지 않는다.

## 맹독뱀 자산

기존 `ThirdParty/XenosNS/SimpleGreenSnake/Original/sSnakeLeft_strip4.png` (CC0)를 `Resources/MonsterAnimations/Snake/snake_move_sheet.png`에 그대로 복사한다. 원본 SHA-256은 `B367FCCC67F2B02A3058EF7245F77FC2003D6927BE3C06D96710E13DC8384B6A`이며 사본과 동일하다. 새 다운로드·원본 이미지 수정은 없다.

원본은 128×32, 좌향 이동 4프레임뿐이며 별도 Idle/Attack은 없다. 공용 SpriteSheet 재생기로 Field 정지/배회 및 Battle Idle/공격에 같은 4프레임을 재사용한다. 전용 공격 프레임을 새로 만들지 않는다. Battle의 기존 SourceFacesRight=false 처리로 오른쪽을 바라보고, 기본 공격의 기존 전진·피해·복귀 연출을 사용한다.

## 공용 Poison

`PoisonDefinition`은 ID, 표시명, DamageMode, Power, Strength를 담는다. 대상별 `PoisonState`는 정의·Source Combatant·남은 Tick을 보관한다. 몬스터 전용 타입으로 만들지 않아 향후 투사 독칼/사수 독화살도 같은 상태 API를 호출할 수 있다. 해당 플레이어 스킬 자체는 구현하지 않았다.

- 일반 독: ID poison, 이름 독, MaxHpPercent, Power/Strength 5, 3 Tick.
- 맹독: ID venom, 이름 맹독, MaxHpPercent, Power/Strength 7, 3 Tick.
- Tick은 독 대상 자신의 행동 종료에 최대 HP 비율을 정수 올림·최소 1로 적용한다. HP 0으로 전투불능이 될 수 있다.
- 방어·철벽·가이아·수호의 맹세 등 직접 피해 감소를 거치지 않는다. 기존 독 Tick의 TakeDamage(applyDefending:false) 경로를 유지한다.
- 상태는 대상당 하나다. 약→강은 교체+3 Tick, 강→약은 거부(남은 Tick도 변경 없음), 같은 강도는 기존 위력 유지+3 Tick 갱신이다. 비교 기준은 표시명이 아닌 Strength다. 5%+7%=12% 중복 Tick은 발생하지 않는다.
- AttackScaling enum은 미래 확장 지점만 두었다. 현재 API는 미구현 피해 모드 부여를 거부한다.
- 독침벌/맹독뱀은 성공 부여 시 자기 독 부여 대기 2를 시작한다. 첫 부여 행동에는 감소하지 않고 이후 자기 행동 종료마다 2→1→0, 다음 공격에서 부여 가능하다. 더 강한 독 때문에 부여가 거부되면 성공 쿨타임을 시작하지 않는다.
- 대상 독 Tick과 시전자 부여 대기는 주인/시점이 다르므로 별도 저장한다. 정화는 부여 대기를 초기화하지 않는다. 양쪽 모두 실제 Combatant 참조 기준으로 독립한다.
- 정화는 `HarmfulStatusType.Poison` 하나만 알면 두 종류 모두 제거한다. Burn/Shock 및 이로운 상태 처리는 유지한다.
- 기존 Venom Ward 상태 아이콘/Acid Splash Tick VFX를 그대로 사용하고 표시명/설명만 데이터의 독·맹독, 5%·7%로 구분한다. VFX Tint·Image 생명주기는 변경하지 않는다.

## Victory와 Save

- EndBattle 승리 분기에서만 EXP 합산 → 진행 계산 → ConfigureProgress → SaveCurrentSession을 실행한다. 종료 중복 호출은 battleEnded 가드로 보상을 반복하지 않는다.
- 도망/패배 보상 0. 파티원별 분배는 구현하지 않는다.
- 결과 Panel은 획득 EXP, 레벨 상승 전후, 현재 EXP/필요 EXP(또는 최고 레벨)를 표시한다. 마우스/키보드 포커스의 `필드로` 버튼으로 확인 후 복귀하며 자동 닫기 제한 시간은 없다.
- 저장은 기존 현재 슬롯 하나만 쓰고, 마지막 안전 월드 Scene/좌표를 유지한다. 승리 확정 후 성장 값만 저장하므로 Battle 중간 HP/MP/턴/상태를 저장하지 않는다. 기존 Field 복귀 후 위치 저장도 유지한다.
- 5슬롯 Version 1의 기존 Level/CurrentExperience 필드를 사용하며 형식을 바꾸지 않는다. 이어하기/삭제/다른 슬롯은 기존 공용 API를 유지한다.

## 검증 순서와 미확정

2026-09-07 검증 결과: 전체 Assembly-CSharp 별도 출력 정적 컴파일 오류 0개/기존 deprecated API 경고 4개. 격리 Unity 6000.5.7f1의 Editor/Play 규칙·15개 버튼 감사와 실제 Field/Battle/저장/리스폰 자동 검증을 모두 통과했다. 뱀 Idle/Attack 4프레임 연결·공격/Idle 전환·우향 반전과 Victory 결과 텍스트 높이 검사도 통과했다. 정상 전투를 끝까지 조작한 검증은 아니며 승리 조건은 테스트가 적 HP를 0으로 만든 뒤 종료 API를 호출했다.

검증 사본의 UnityEditor.Search 초기 인덱싱에서 ArgumentOutOfRangeException 1건이 별도로 발생했다. 게임 코드의 컴파일/검증 실패는 없었고 이후 전체 검증이 완료되었다. 검색 패키지·사용자 프로젝트 설정은 이 작업에서 변경하지 않았다. 실행 로그: 로컬 `Unity/Client/Logs/early-leveling-isolated.log` (`EARLY_LEVELING_AUDIT ALL PASS`).

`EarlyLevelingAudit.RunBatch`는 EXP 곡선·이월/연속/만렙·레벨차 경계·반올림·몬스터 조우/HP/Attack/합산·공용 독/강도/정화/개체별 대기/JSON 왕복과 기존 15개 버튼 아이콘을 검증한다. 별도 `Temp/Lv` 프로젝트 사본의 테스트용 5슬롯에서 저장/로드 및 Field_02 6개 생성 → 뱀 Battle → 52 EXP/레벨업 결과/중복 승리 가드/현재 슬롯 저장/다른 슬롯 불변 → Field 복귀/30초 리스폰/진행 재로드를 검증한다. 사용자 원본 UserData는 복사하거나 변경하지 않는다. 최초 전체 Import의 패키지 긴 경로 문제를 피하도록 검증 경로를 짧게 두며, 경로 가드가 원본 프로젝트에서의 자동 저장 검증을 거부한다.

사용자 Play Mode 순서:
1. 테스트용 슬롯에서 각 필요 EXP, 초과 EXP·연속 레벨업, Lv50 제한 확인.
2. Lv10 기준 몬스터 Lv3/4/6/7/13/14/16/17의 이름색과 EXP 경계 확인. 플레이어/NPC 흰색 확인.
3. 슬라임/벌/거미/뱀 조우 구성, HP 60/70/80/95, Attack 10/12/14/16과 합산 확인.
4. 뱀 2개 위치·배회·전투 오른쪽 방향/공격/리스폰 확인.
5. 5%×3 및 7%×3, 약→강/강→약/같은 강도 재적용, 최소 피해·전투불능·정화, 방어와 독립한 Tick 확인.
6. 복수 벌/뱀 독 부여 2→1→0과 정화 후 대기 유지 확인.
7. Victory 결과 확인 후 재실행하여 현재 슬롯 Level/EXP/위치 복원, 다른 슬롯 불변, 도망/패배 EXP 0 확인.
8. 모든 직업 스킬·버튼 아이콘·VFX·Timeline·Tie Break·Targeting·Field 전환 회귀 확인.

미확정: 레벨업 HP/MP 완전 회복, 수호자/치유사 6능력치 성장, 최종 밸런스. Field_03·플레이어 독 스킬·장비/휴식/퀘스트 EXP·파티 분배·보스/Elite 특별 공식·Level Sync는 이번 범위가 아니다.
