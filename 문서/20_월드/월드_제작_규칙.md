# 월드 제작 규칙

## 공통 경계 원칙

모든 World/Field Scene은 `WorldBounds2D`를 가져야 한다.

`WorldBounds2D`는 배경 Tile이 실제로 채우는 플레이 가능 영역의 중심과 크기를 정의한다. `CameraFollow`는 이 Bounds를 선택적으로 참조하며, Orthographic Camera의 세로 반경과 `camera.aspect`로 계산한 가로 반경을 포함해 화면 전체를 Bounds 안에 제한한다.

외곽 Collider는 `WorldBoundaryGeneratorUtility.Create`로 생성한다. 기본적으로 상·하·좌·우 네 면을 닫고, `WorldBoundaryOpening`으로 선언한 출입구 구간만 비운다. 출입구에는 `SceneTransitionTrigger`를 배치하고 Spawn Point는 Trigger와 충분히 떨어뜨려 진입 직후 역전환되지 않게 한다.

## 새 Field 제작 체크리스트

- `WorldBounds2D` 중심과 크기
- `CameraFollow` Bounds 연결
- 4면 Boundary Collider
- 명시적인 Exit Opening
- `SceneTransitionTrigger` 대상 Scene/Spawn ID
- Trigger와 분리된 `SceneSpawnPoint`
- Game View 좌·우·상·하 외부 노출 검사
- 외곽 SpriteRenderer가 Bounds 밖 검은 영역에 돌출되지 않는지 검사
- Player 기본/Path Visual/Wheelchair Variant 이동 검사
- Console Error, Missing Reference 검사
