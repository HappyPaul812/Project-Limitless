# 침묵의 지하묘지 B1

- Scene ID `Dungeon_01`, 표시 지역명 `침묵의 지하묘지 B1`.
- Field03의 Main10 완료 입구 상호작용이 기존 `SceneTransitionService`로 `Spawn_From_Field03`에 진입한다. B1 남쪽 출구는 `Spawn_From_Dungeon01`을 목적지로 Field03에 복귀한다. Field03 쪽은 기존 Quest 입구를 우회하는 자동 전환 Trigger 없이 복귀 Spawn만 설치한다.
- 입구 홀(전투 없음) → 중앙 회랑(B1-01) → 서쪽 안치실(B1-02)·동쪽 무너진 묘실(B1-03) → 북쪽 회랑(B1-04) → 봉인된 하강로 순서다. B2 연결과 상호작용은 없다.
- B1-01은 묘지 망자 1, B1-02는 묘지 망자 1·그늘박쥐 1, B1-03은 묘지 망자 2, B1-04는 묘지 망자 1·그늘박쥐 2다. 모든 배치는 기존 `FieldMonsterSpawnDefinition`을 사용하며 접촉·승리 제거·도망·35초 리스폰·보상은 일반 필드 정책을 따른다.
- `WorldBounds2D`는 중심 `(0, 0)`, 크기 `33×25`이며 카메라 Orthographic Size 5와 기존 `CameraFollow`의 화면 비율별 제한을 사용한다. 네 면 Collider는 닫혀 있고 남쪽 출구 Trigger는 경계 안쪽에 있다. 던전 Spawn `(0, -8.5)`과 출구 `(0, -11.9)`는 3.4유닛 떨어져 있다.
- 환경은 기존 Kenney RPGBase의 회색 석재 `rpgTile152` Sprite를 착색·확대해 구성한다. 별도의 전용 묘지 Prop Asset이 없어 서쪽 안치대, 동쪽 잔해, 횃불 받침, 북쪽 봉인을 단순한 형태로 표시한다. 사용자 원본 이미지와 ThirdParty 원본은 변경하지 않았다.
- 향후 Quest 위치는 `EntranceHall`, `CentralGallery`, `WestOssuary`, `EastCollapsedChamber`, `dungeon01_b1_lower_descent` GameObject를 기준으로 연결할 수 있다. 이번에는 Main11 정의·목표·대사·Navigation을 추가하지 않았다.
