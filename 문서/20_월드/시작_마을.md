# 시작 마을 1차 허브

## 역할

`World_StarterVillage`는 캐릭터 생성 직후 도착하고 `Field_01` 탐험 전후에 정비하는 1장 시작 거점이다. 기존 19×13 지도, 중앙 남북 길, 두 건물, 자연물, Player·Camera·남문 전환 구조는 유지한다.

## 1차 구역

- 중앙 광장: OGA-09 주민 대표 역할 NPC. 현재는 마을과 남문 동선만 안내하며 이름·성격·퀘스트 내용은 확정하지 않는다.
- 시장: 잡화점·장비점 역할 NPC. 거래 UI가 연결될 안정적인 역할 진입점만 둔다.
- 치유소/여관: 확인 후 `PartyResourceService.HealPartyFully()`로 등록된 파티 HP/MP를 무료 완전 회복하고 현재 슬롯을 즉시 저장한다.
- 안전 서비스: 은행·파티 관리 역할 NPC. 보관·편성 시스템은 구현하지 않으며 Taeon/Miel을 월드 NPC로 배치하지 않는다.
- 훈련 구역: 향후 기초 훈련을 위한 안내 역할만 둔다.
- 생활 구역: 퀘스트를 확정하지 않은 주민 4명으로 마을 생활감을 보완한다.
- 남문: 기존 `Field_01` 왕복 Trigger와 Spawn을 유지하고 경비병 안내 역할을 둔다.

## 구현 원칙

- 기능 분기는 표시 이름이 아니라 `VillageNpcRoleType`과 stable NPC ID를 사용한다.
- NPC는 정확한 방향이나 빠른 반응을 요구하지 않는 기존 2m 근거리 상호작용을 사용한다.
- 새 배치는 `Chapter01_StarterVillageHub` 아래의 역할별 Zone으로 묶고 기존 환경을 삭제하거나 재생성하지 않는다.
- 역할 NPC 8명은 Eldiran CC0 `32x32 RPG Character Sprites`의 승인된 외형을 stable NPC ID로 연결한다. 잡화상 OGA-03, 장비상 OGA-17, 치유사 OGA-06, 은행 OGA-16, 동료 편성 OGA-10, 훈련장 관리 OGA-02, 남문 경비 OGA-20, 주민 대표 OGA-09다.
- 원본 시트는 ThirdParty에 그대로 보존하고, 정확한 마젠타 크로마키만 투명화한 32×32 파생본을 `_Project/Resources/VillageNpcSprites/Eldiran`에서 사용한다.
- 일반 주민 4명은 외형 미확정 상태이므로 기존 `VillageNpcPlaceholder` 외형을 유지한다.
- 잡화점·장비점·은행·파티 관리·훈련은 역할 진입점이며 실제 시스템 범위는 후속 작업에서 별도로 정한다.
- 시작 마을 NPC 이름표는 흰색 한 줄 중앙 정렬을 유지한다. 기본 TextMesh 폰트 크기 40·character size 0.075를 사용하고, 7자 이상 이름은 0.065로 줄여 무리한 줄바꿈 없이 표시한다.
- 이름표는 NPC 기준 Y 1.02에 두고 검은 그림자를 더해 머리·모자 및 밝은 배경과 구분한다. 상호작용 안내는 Y 1.48로 분리해 이름표와 겹치지 않게 한다.
- NPC 이름표는 Player의 Screen Space 이름·레벨 표시와 별도 구현이며, NPC 조정이 플레이어 표시 높이와 스타일에 영향을 주지 않는다.

## 검증 체크리스트

- 중앙 길과 남문 진입로가 NPC로 막히지 않는지 확인
- 모든 역할 NPC가 E/F·게임패드 South로 가장 가까운 대상과 상호작용하는지 확인
- 치유 확인/취소, 완전 회복, 즉시 저장, Continue 이후 자원 유지 확인
- 남문 → `Field_01` → 마을 왕복과 Spawn/Trigger 비중첩 확인
- Camera가 19×13 Bounds 밖 검은 영역을 노출하지 않는지 확인
- 주민·잡화 상인·은행 안내인·훈련장 관리인·주민 대표 등 전체 NPC의 이름표가 스프라이트 및 서로와 겹치지 않는지 확인
- Player가 NPC에 접근했을 때 이름표와 `[E] 대화하기` 안내가 서로 겹치지 않는지 확인
