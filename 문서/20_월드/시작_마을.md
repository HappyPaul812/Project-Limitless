# 시작 마을 1차 허브

## 역할

`World_StarterVillage`는 캐릭터 생성 직후 도착하고 `Field_01` 탐험 전후에 정비하는 1장 시작 거점이다. 기존 19×13 지도, 중앙 남북 길, 두 건물, 자연물, Player·Camera·남문 전환 구조는 유지한다.

## 1차 구역

- 중앙 광장: OGA-09 주민 대표 역할 NPC. 현재는 마을과 남문 동선만 안내하며 이름·성격·퀘스트 내용은 확정하지 않는다.
- 시장: 잡화상은 실제 구매·판매 Shop을 제공한다. 장비상은 아직 대화 진입점만 둔다.
- 치유소/여관: 확인 후 `PartyResourceService.HealPartyFully()`로 등록된 파티 HP/MP를 무료 완전 회복하고 현재 슬롯을 즉시 저장한다.
- 안전 서비스: 은행·파티 관리 역할 NPC. 보관·편성 시스템은 구현하지 않으며 Taeon/Miel을 월드 NPC로 배치하지 않는다.
- 훈련 구역: 향후 기초 훈련을 위한 안내 역할만 둔다.
- 생활 구역: 퀘스트를 확정하지 않은 주민 4명으로 마을 생활감을 보완한다.
- 남문: 기존 `Field_01` 왕복 Trigger와 Spawn을 유지하고 경비병 안내 역할을 둔다.

## 구현 원칙

- 기능 분기는 표시 이름이 아니라 `VillageNpcRoleType`과 stable NPC ID를 사용한다.
- NPC는 정확한 방향이나 빠른 반응을 요구하지 않는 기존 2m 근거리 상호작용을 사용한다.
- 새 배치는 `Chapter01_StarterVillageHub` 아래의 역할별 Zone으로 묶고 기존 환경을 삭제하거나 재생성하지 않는다.
- 역할 NPC 8명은 Eldiran CC0 `32x32 RPG Character Sprites`의 승인된 외형을 stable NPC ID로 연결한다. 잡화상 OGA-03, 장비상 OGA-17, 치유사 OGA-06, 은행 OGA-16, 동료 편성 OGA-10, 훈련장 관리 OGA-02, 남문 경비 OGA-20, 주민 대표 OGA-09다.
- 원본 시트는 ThirdParty에 그대로 보존하고, 정확한 마젠타 크로마키만 투명화한 32×32 파생본을 `_Project/Resources/VillageNpcSprites/Eldiran`에서 사용한다.
- 일반 주민 4명은 stable NPC ID를 유지하며 주민 1 OGA-07, 주민 2 OGA-11, 주민 3 OGA-13, 주민 4 OGA-19를 사용한다. 실제 외형 적용 뒤 `PlaceholderVisual`과 주황색 임시 Sprite는 제거한다.
- 잡화상은 stable `GeneralShop` 역할에서만 `shop_general_starter_village`를 연다. 구매 탭은 회복약(20/10 탈렌트)과 마력 회복약(30/15 탈렌트)을 표시하고, 판매 탭은 현재 Inventory의 판매 가능 소비품·Material을 이름과 보유량으로 표시한다. Quest/KeyItem·판매가 0·Count 0은 제외한다. 장비점·은행·파티 관리·훈련은 아직 역할 진입점만 유지한다.
- 일반 주민은 상시 이름표를 표시하지 않고 공통 Interaction Prompt로 상호작용 가능 여부를 알린다. 기능 NPC는 역할명 한 줄, 주민 대표·향후 퀘스트 중요 NPC는 역할명 또는 정식 이름 한 줄, 태온·미엘 같은 고유 캐릭터는 실제 이름 한 줄을 표시한다.
- 표시하는 시작 마을 NPC 이름표는 흰색 한 줄 중앙 정렬을 유지한다. 기본 TextMesh 폰트 크기 40·character size 0.075를 사용하고, 7자 이상 이름은 0.065로 줄여 무리한 줄바꿈 없이 표시한다.
- 이름표는 NPC 기준 Y 1.02에 두고 검은 그림자를 더해 머리·모자 및 밝은 배경과 구분한다. 상호작용 안내는 Y 1.48로 분리해 이름표와 겹치지 않게 한다.
- NPC 이름표는 Player의 Screen Space 이름·레벨 표시와 별도 구현이며, NPC 조정이 플레이어 표시 높이와 스타일에 영향을 주지 않는다.
- World EXP HUD는 탐험 중 표시하되 NPC 대화·치유 확인 등 상호작용 UI가 열리면 숨기고 종료 후 복귀시킨다. 향후 상점·은행·동료 편성·퀘스트 UI도 같은 소유자 기반 표시 억제 API를 사용한다.
- 대화 Canvas는 World HUD Canvas보다 높은 sortingOrder를 사용하고 Panel을 마지막 sibling으로 올려, HUD 숨김이 실패해도 대화창이 앞에 보이게 한다.
- NPC 상호작용 진입 거리는 2.0, 대화 유지 종료 거리는 3.0으로 공통 관리한다. 플레이어 이동은 막지 않으며 대화 상대의 실제 Transform과 플레이어 Transform 거리가 3.0을 넘거나 어느 한쪽이 비활성·제거되면 기존 Hide 경로로 닫는다.
- Shop Canvas는 sortingOrder 20의 상호작용 Modal이다. 열려 있는 동안 World EXP HUD와 월드 이동을 억제하고, Esc·게임패드 B·닫기 버튼·상점 NPC 소실·InteractionSystem 비활성화·Scene 전환에서 공통 Close로 모두 복귀한다. Tab/Shift+Tab·방향키·Enter/Space·게임패드 UI 입력을 지원한다.
- 수량은 구매/판매 모드별 `-`·`+`·`최대` 버튼으로 조절한다. 기본 1, 구매 최대는 자금과 남은 MaxStack, 판매 최대는 보유량이며 모드나 아이템을 바꾸면 1로 초기화한다. 활성 탭은 `[구매]`/`[판매]` 텍스트로 구분하고 실행 버튼도 현재 모드의 `구매` 또는 `판매` 하나만 표시한다. 전량 판매 행은 제거하고 다음 행으로 안전하게 이동하며 빈 목록 안내를 제공한다.

## 검증 체크리스트

### 파티 안내인

- 기존 `starter-village-party-manager`가 실제 파티 편성 UI를 연다. 새 NPC나 필드 단축키는 추가하지 않는다.
- Main05의 태온·미엘 해금 직후부터 사용 가능하며 Main09 완료 후 폴이 같은 동적 목록에 추가된다.
- Player 고정 + 동료 최대 2명, 전열/후열, 확정/취소, 공격 역할 부족 경고를 제공한다. 저장·일반 전투·Story Override 정책은 `문서/10_전투/동료_파티_편성.md`를 따른다.
- 편성 화면은 `WorldModalState`와 이동 잠금을 소유한다. 확정/취소/Esc/게임패드 B 또는 Scene 종료에서 해제한다.

- 중앙 길과 남문 진입로가 NPC로 막히지 않는지 확인
- 모든 역할 NPC가 E/F·게임패드 South로 가장 가까운 대상과 상호작용하는지 확인
- 치유 확인/취소, 완전 회복, 즉시 저장, Continue 이후 자원 유지 확인
- 남문 → `Field_01` → 마을 왕복과 Spawn/Trigger 비중첩 확인
- Camera가 19×13 Bounds 밖 검은 영역을 노출하지 않는지 확인
- 주민·잡화 상인·은행 안내인·훈련장 관리인·주민 대표 등 전체 NPC의 이름표가 스프라이트 및 서로와 겹치지 않는지 확인
- Player가 NPC에 접근했을 때 이름표와 `[E] 대화하기` 안내가 서로 겹치지 않는지 확인
- 일반 주민·기능 NPC·주민 대표 대화 중 World EXP HUD가 숨고 Esc/취소·종료 후 복귀하는지 확인

## 일반 주민 외형·이름표 검증

- Unity 6000.5.7f1 Play Mode에서 주민 1~4가 각각 OGA-07/11/13/19로 로드되고 흰색 SpriteRenderer, 물리 BoxCollider2D `(0.50, 0.34)`, 기존 CircleCollider2D 상호작용 Trigger를 유지하는 것을 확인했다.
- 주민 4명은 직접 Label 1개만 가지며 모두 비활성, 기능 NPC 7명과 주민 대표는 활성 Label 1개와 줄바꿈 없는 역할명만 가진다. 주민 4명의 기존 대사 데이터와 공통 상호작용 호출도 4/4 확인했다.
- `Field_01` 로드 뒤 `World_StarterVillage` 복귀와 주민 런타임 재설치가 정상이며, Game View에서 주황색 Placeholder·마젠타 배경·일반 주민 상시 이름표가 보이지 않는다.
- 전체 비교 화면: `Unity/Client/ValidationCaptures/starter_village_npc_final_overview.png`. Interaction Prompt 근접 화면: `Unity/Client/ValidationCaptures/starter_village_resident_interaction_prompt.png`.
- 기능 관련 Console Error는 0개다. 저장 슬롯 없이 World Scene을 직접 연 검증 방식 때문에 기존 자동 저장 건너뜀 경고가 3회 있었고, NPC 외형·이름표 관련 신규 Warning은 없다.

## 대화 UI와 World EXP HUD 검증

- Unity MCP Play Mode에서 일반 주민, 잡화 상인, 주민 대표 대화가 열릴 때 World EXP HUD CanvasGroup alpha 0·blocksRaycasts false, 닫힐 때 alpha 1로 복귀함을 확인했다.
- 대화 Canvas sortingOrder 10, PlayerNameplate·World EXP HUD Canvas sortingOrder 5, DialoguePanel 마지막 sibling을 확인했다.
- 연속 대화 3회 모두 숨김/복귀했고 `World_StarterVillage → Field_01 → World_StarterVillage` 왕복 뒤에도 HUD 표시와 재대화 숨김/복귀가 정상이다.
- 기능 관련 Console Error는 0개다. 저장 슬롯 없이 World Scene을 직접 연 검증 경로의 기존 자동 저장 건너뜀 Warning 1개만 발생했다.
- 거리 이탈 검증에서 2.5 거리에서는 대화가 유지되고 3.1에서는 자동 종료·HUD 복귀했다. 범위 밖에서는 Interaction Prompt 대상이 없고 재접근하면 Prompt와 재대화가 복구됐으며 일반 주민·잡화상·주민 대표 및 자동 종료 3회 반복, Field_01 왕복 후 공통 거리 2.0/3.0 유지를 확인했다.
