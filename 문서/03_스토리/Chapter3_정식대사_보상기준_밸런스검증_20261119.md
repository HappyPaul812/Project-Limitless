## A. Main22~29 장면별 대사 기준
### Main22 북풍의 징후 (F1)
- 출발 선택: 세린 “장갑을 하나 더 챙겨야겠어요. 활시위를 잡는 손이 먼저 차가워질 것 같아서요.” / 미엘 “저는 따뜻한 차부터 챙길래요.” / 폴 “저는 돌아올 길을 확인해 두겠습니다.”
- 서리/발자국 조사: 세린 “발자국이 모두 남쪽으로 향하고 있네요.” / 미엘 “부상 흔적은 많지 않아요. 서둘러 옮겨 간 것 같네요.” / 폴 “그늘진 땅은 얇게 얼었어요. 단단한 쪽으로 가죠.”
- 첫 서리들쥐 예고: 태온 “잠깐만요. 길목에 작은 짐승이 있습니다. 놀란 것 같으니 조심하세요.”
- 승리 후: 하렌 “넌 꼭 앞에 나서야 마음이 놓여?” / 태온 “무턱대고 나간 거 아니야. 돌아갈 길도 봤어.” / 하렌 “…다음엔 먼저 말해.” / 태온 “내 말부터 좀 들어 줘.” / 세린 “더 안쪽에서 무슨 일이 있는지 확인해야겠네요.” / 플레이어 “먼저 돌아올 길을 표시합시다.”
### Main23 따뜻한 땅을 떠난 자들 (F1→서릿길)
- 깊은 흔적: 세린 “먹이까지 남겨 두고 남쪽으로 갔네요.” / 태온 “저쪽 길에도 같은 흔적이 있어요.” / 하렌 “흔적이 있다고 무턱대고 따라갈 거야?” / 태온 “돌아올 길부터 확인했어.”
- 접근: 폴 “이쪽 흙은 아직 단단하네요. 여기라면 모두 지나갈 수 있겠습니다.” / 미엘 “좋아요. 잠깐 멈춘 김에 손도 녹이죠.”
- 남문: 오르나 “멀리서 오셨군요. 요 며칠은 남쪽으로 가는 짐승이 눈에 띄게 늘었어요.” / 세린 “저희도 오는 길에서 봤어요.” / 오르나 “지붕의 서리가 낮에도 잘 안 녹아요. 전에는 이렇게 춥지 않았는데… 어디가 더 안전했나요?” / 하렌 “그건 내가…” / 태온 “형. 내가 본 거니까 내가 얘기할게. 왼쪽 둔덕이 덜 얼었어.” / 오르나 “그 길을 마을 사람들에게도 알려야겠군요.”
- 종료/거점 안내 오르나 “여기는 서릿길 마을입니다. 쉬어 가셔도 좋아요. 북쪽 길은 준비가 되면 이용하세요.” 별도 상점 자동 구매 없음.
- 여관 선택: 세린 “여기선 장갑을 벗어도 금세 차가워지네요.” / 미엘 “그래도 차가 따뜻하잖아요.” / 도아 “다들 천천히 드세요.” / 폴 “미엘 씨, 차가 식기 전에 드세요.” / 미엘 “폴 씨도요. 오늘은 둘 다 식기 전에 마시는 걸로 해요.”
### Main24 첫눈 아래의 경고 (F2)
- 루덴 “새 기술을 익히거나 이미 아는 기술을 강화할 수 있지요. 무엇을 배울지는 여러분의 선택입니다.”
- 마레 “북쪽에서는 한기에 걸리면 두 차례 행동하지 못할 수 있어요. 이 어묵탕 두 그릇을 가져가세요. 행동할 수 있는 동료가 한기에 걸린 사람에게 써 주세요.” 지급은 메인 준비에서 1회; 구매·서브 필수X.
- 출발: 세린 “첫눈이네요. 장갑을 더 챙기길 잘했어요.” / 미엘 “저는 어묵탕부터 생각나는데요?” / 세린 “그건 비상용이에요!” / 폴 “두 분 다 준비는 확실하시군요.”
- 조사/올빼미: 세린 “날개를 펼칠 때 주변 눈이 한곳으로 모여요. 조심하세요.” / 하렌 “태온, 네가 괜히 앞에 나설 필요 없잖아.” / 태온 “형, 먼저 어떤 공격인지 보고 대비하자는 거야.” / 하렌 “…그래. 계속 말해 봐.”
- 승리: 미엘 “한기에 걸린 동료는 다른 사람이 도와야 해요.” / 폴 “추위가 더 깊은 곳에서 흘러오는 모양입니다.” / 플레이어 “고갯길로 가서 원인을 찾아봅시다.” 기존 첫 한기 예고·최대1회·복귀보호 유지.
### Main25 끊어진 온맥 (F3)
- 표식1: 세린 “이쪽만 서리 모양이 다르네요. 바람 방향과도 맞지 않아요.” / 폴 “마력 표식입니다. 이곳에서 흐름이 끊긴 모양이에요.”
- 표식2: 폴 “원래 이쪽으로 흘렀다면… 지금은 반대로 끌려가는군요.” / 태온 “돌아갈 수 있게 길부터 표시하자.” / 하렌 “…그래. 어디로 가는 게 좋겠어?”
- 갑충 예고: 세린 “갑각을 닫으면 공격이 잘 통하지 않을 것 같아요.” / 태온 “몸을 움츠릴 땐 다른 행동으로 대비하죠.”
- 승리/다음: 미엘 “북쪽에 쉬던 사람들이 있을지도 몰라요.” / 폴 “이 흔적을 따라가면 피난처에 닿을 겁니다.” / 플레이어 “그쪽부터 확인합시다.”
### Main26 사라지는 피난처 (F4)
- 보급: 마레 “이번에는 동상에 대비하세요. 해빙 연고 두 개를 준비했습니다. 한기와 동상은 다른 상태예요. 연고는 동상에 써 주세요.” 단회 지원/실제 수령 위치는 기존 동선 감사.
- 쉼터: 피난 주민 “원래 이곳은 잠시 몸을 녹일 수 있었어요. 이제는 길마저 얼어서 움직이기 어렵네요.” / 미엘 “먼저 상태를 확인할게요. 서둘러 움직이지 마세요.” / 세린 “눈바람이 한곳에 모이고 있어요.”
- 정령 예고: 폴 “마력이 응축되고 있습니다. 저 공격은 한기보다 위험할 수 있어요.” / 미엘 “동상은 행동하지 못하는 동안 체력도 줄어듭니다. 연고를 준비해 주세요.” 기존 승인 전투 규칙 그대로.
- 갈등: 하렌 “위험하니까 넌 안에 있어. 내가 확인하고 올게.” / 태온 “형, 나 혼자 하겠다는 게 아니야. 우리가 어디로 갈지 같이 정하자는 거야.” / 하렌 “네가 다치면 어쩌려고!” / 태온 “나도 형이 다치는 건 싫어. 그래서 혼자 가게 두기 싫은 거야.” / 플레이어 “함께 길을 확인합시다.” / 세린 “저는 바람이 덜 부는 쪽을 볼게요.” / 폴 “바퀴와 짐수레가 지나갈 길을 확인하겠습니다.” / 미엘 “저는 주민들의 상태를 살필게요.” / 하렌 “…알았어. 같이 가자.”
- 철수 성공: 주민 “이제 돌아갈 길을 알겠어요. 정말 고맙습니다.” 안전 경로 확인+대화, 시간제한/실시간 호송 없음.
- 쉼터 수다: 세린 “미엘 씨, 폴 씨가 요즘 미엘 씨 몫의 차부터 챙기던데요?” / 미엘 “어머, 그런 것까지 보고 계셨어요?” / 세린 “하하, 제가 사수잖아요. 놓치는 게 별로 없죠.” / 미엘 “그럼 저도 조심해야겠네요.” / 세린 “그런데 미엘 씨는 다른 분들 치료부터 하시면서, 정작 자기 손은 왜 늘 나중이에요?” / 미엘 “……예전에도 저한테 먼저 치료받으라고 하던 사람이 있었어요.” (짧은 여백) / 세린 “그럼 이번엔 제 말도 들어 주세요. 차 식기 전에 마셔요.” / 미엘 “네. 이번엔 그럴게요.” 여성 플레이어가 추가 선택 시 “두 분 차가 식기 전에 저도 한 잔 할래요.” 주요 장면은 성별 무관. 전쟁·약혼·사망 등 직접 공개 금지.
- 마무리: 태온 “이제 더 북쪽을 확인해 보죠.” / 하렌 “그래.”
### Main27 얼음 너머의 불빛 (F5)
- 흔적: 폴 “얼음 사이로 마력이 새어 나오고 있어요. 저 금빛이 온기의 근원인 것 같습니다.” / 세린 “그 앞에 움직이는 구조물이 있어요.” / 태온 “먼저 주변을 확인하고 접근하죠.”
- 빙각 수호체 예고: 하렌 “팔을 들었어. 큰 공격이 오겠군.” / 태온 “방어할 준비를 하세요.” 기존 180% 예고 강타/단독전.

- 결전 전: 미엘 “폴 씨, 오늘은 제 몫까지 휴식 시간을 챙겨 두었어요.” / 폴 “다행인데요. 제가 괜한 걱정을 한 건가요?” / 미엘 “아뇨. 걱정해 주시는 게… 싫지는 않아요.” / 폴 “그러면 저도 조금은 안심해도 되겠네요.” / 미엘 “이 일이 끝나면, 둘이서 따뜻한 차 한 잔 할까요?” / 폴 “좋습니다. 그 약속은 꼭 지키겠습니다.”
