## 1. 위치·역할·세계관

**작업명:** `서릿길 마을` (가칭, 추후 미술/대사 단계에서 확정). 시각 아이덴티티: *북쪽 길을 지키며 계절을 견디는 사람들이 사는 작고 실용적인 마을*. 아르벨과 겹치지 않는 **회갈색 돌기초, 따뜻한 목재, 어두운 천 지붕, 장작더미, 얇은 지붕서리**, 실제 거주 흔적. **완전한 설원 마을이 아니다**.

**노선:** Chapter1 초보 마을(Main21 완료·펫 서비스 공개) → Chapter3 F1 `북풍의 들머리`(Main22 첫 전투, Main23 심부 조사) → **서릿길 마을(안전지역, Main23 완료)** → F2 `첫눈의 숲`(Main24 한기 학습) → F3→F4→F5→보스전. 마을은 **북부 일반 필드 5 + 보스전 1**의 필드 개수에 포함하지 않는다. Main26 `사라지는 피난처`는 **F4의 별도 쉼터**다.

북부 주민이 버틴 이유는 **오직 한 개의 본원 마법 `온기의 화로`가 멀리까지 영향을 미쳐 왔기 때문**이라는 사용자 정본에 연결한다. 마을의 장작난로와 모닥불은 **일반 난방**이며 보스 전용 화로의 동결괴사 제거·전투 명령·특별한 즉시 치유를 복제하지 않는다. Main23 주민은 현상만 말하고 화로/폭군의 모든 진상을 설명하지 않는다.

## 2. 마을 평면 구조 — 1차 블로킹 설계

**권장 방향:** 남쪽=F1 귀환, 북쪽=F2 진입, 동쪽=장래 순간이동 광장, 서쪽=작은 주거/창고. **남북 간선**은 이번 북진 Chapter3에 맞춘 방향(Chapter2 Field05의 서진 동서 간선과 혼동하지 않음).

**블록 배치 개념도 — 실제 Unity 좌표/치수·Collider 계약이 아닌 레이아웃 초안:**

```text
                     북쪽 → F2 첫눈의 숲
                  [북문 / 출발 경고 표지]
                          │
   [주거 / 장작창고]    [북쪽 길]       [보급·해제약]
          │               │                │
   [여관·회복] ─────── [중앙 광장] ─────── [스킬 상점]
          │               │                │
   [주민·의뢰 게시판]  [정보·파티 안내]    [포탈 광장 진입로]
          │               │                │
   [서쪽 생활터]       [입구 안내]     ┌───────────────────┐
          │               │          │ 후일 순간이동 전용 │
          └────── [남문 / F1] ─────── │ 돌기단·빈 부지      │
                                     │ 포탈/도착점 별도    │
                                     └───────────────────┘
```

**길/서비스 우선:** 입구에서 중앙→스킬 상점·여관·북문까지 이어지는 **폭 넉넉한 비충돌 간선**; 가게 문과 표지판을 길 중간에 두지 않음. 포탈 광장은 동쪽 **곁가지 막다른 넓은 공간**으로, 훗날 사용자가 실수로 닿아 월드 이동하거나 북문을 막지 않게 분리. 포탈 광장을 반드시 통과해야 스킬을 살 수 있는 구조 금지.

## 4. 포탈 예약지: 향후 기술 설계 계약

**권장 연출:** 건물 사이 작은 포탈이 아닌, **동쪽 열린 공터의 둥근 돌기단과 빈 링 자리**. 처음에는 **평범한 석재 기초** 또는 “오래된 이동석 자리” 정도의 표식을 두되 기능을 암시하는 과한 입자/퀘스트 느낌표/활성 PortalFX 없음. 보스 전용 `온기의 화로`와 색·모양을 구분한다.

**별도 구역으로 미리 예약할 논리 슬롯 (구현 ID 확정 아님):**
- `FuturePortalPad_Reserved`: 장래 기단 설치 범위. 지금은 비작동.
- `FuturePortalLanding_Reserved`: 외부 이동 후 나타날 안전 Spawn 후보. 기단 Collider/Trigger와 독립.
- `FuturePortalQueue_Reserved`: 대기 및 접근 경로. 향후 Portal NPC와 상호작용 포켓으로 확장할 수 있으나 현재 NPC 없음.
- `FuturePortalClearance_Reserved`: 기단 주변 360° 가림·나무/처마·보행 충돌 금지 완충구역.

**하드 NO:** `SceneTransitionTrigger`, `FieldConnectionDefinition`, 활성 `PortalAnchor`, Fast Travel 버튼/맵 선택/텔레포트 처리를 현재 만들거나 기존 ID로 연결 금지. 미사용 오브젝트는 **비활성 인터랙션/툴팁**이거나 기단 아트만. 앞으로 기능 개발 시에는 별도 데이터 계약/TargetSpawn/ID 유일성/도착 검증/씬 로딩 세이브/자동 역전환/특수 이동과 SafeZone 중첩 등을 독립 테스트.

**향후 활성화 QA 수락 게이트**:
1. 시각적으로 다른 건물 지붕·나무·깃대·표식이 포탈과 겹치지 않는지 4방향 카메라/모든 비율 비교.
2. 도착 Spawn이 포탈 이벤트 영역과 겹치지 않고 즉시 재발동·연쇄씬 전환 0.
3. 도보/휠체어 각각 입장·대기·취소·이동 후 귀환 가능.
4. 포탈을 사용하지 않아도 북문/남문/스킬상점/체크포인트 접근 가능.
5. 연출 VFX는 점멸/화면 번쩍임 강제·음성 의존 없이 시각/자막/아이콘으로 식별 가능.
6. Main23 완료 전 포탈 비작동, 해당 저장상태를 통한 서비스 오픈 조건 검증 (정확 시점 TBD).

## 5. 주민 구성과 지역 사건(퀘스트/이름 ID 미정)

**최소 기능 역할 5~7개**를 서로 다른 GameObject/NPC 수와 동일시하지 않는다: 마을 안내인/책임자, 기술/스킬 상인, 생활상인(방한·약), 여관/회복 담당, 파티/펫 서비스 담당(기존 시스템 연동), 마을 주민1~2 및 조사 안내. 실제 구분된 NPC 수는 Scene 실측·UI 과밀·TTS 비용에 맞게 축소 가능. **서릿길 마을은 물건을 사고 떠나는 곳뿐 아니라 사람들이 살아 있는 공간**.

**서브퀘스트 후보 (메인 Quest blocker 아님)**:
- `얼어붙지 않은 길`: 안전한 짐수레 운반로 표시 및 주민 이동 돕기(조사+대화, 몬스터 10마리 처치 요구X). 폴·휠체어 사용자 본인의 판단으로 통행 가능한 코스를 함께 표시.
- `돌아오지 않는 발자국`: 겨울 먹이가 사라진 흔적을 탐색, 세린이 추적 논리 제공. 야수 무조건 사냥·멸종 구조로 단순화하지 않음.
- `따뜻한 한 잔`: 숙소의 차/장작 재료를 전달해 일상 생활을 경험, 마을 분위기와 미엘·세린 수다 공간 제공. 직접적인 전쟁 상실·약혼자 정보 스포일러 금지.

**Main23~24 메인 이벤트**
1. Main23 F1의 이상한 동물 남하 조사 후 마을 남문에 도착. 주민의 생활 불편을 직접 듣고 마을 이름/안전지역을 안내, 체크포인트와 상품/숙소 접근을 열어 준다. **Main23 목표 마지막=마을 거점 확인 후 완료**; F2 첫눈은 아직 본격적으로 보지 않는다.
2. Main24는 마을 안에서 한기의 위험과 대응 조언을 받고, 첫 스킬 상점/일반 상점의 메뉴 사용을 **선택적으로 보여 준 뒤** F2 북문으로 출발. 스킬 구입 자체를 Main24 진행 필수로 삼지 않음. 한기 대응 조치는 강제전투 전 선택 가능한 보장된 방법으로 설계.
3. Main25~27 중 필드에서 언제든 마을 회귀가 가능하도록 북문/남문 상태 유지. Chapter3 중반 주민의 화덕 사용량/옷차림 변화로 지역의 악화를 표현하되 **실시간 날씨·제한시간 기믹 없음**.
4. Main29 마지막 후일담에서 마을 주민들이 옅게 돌아온 온기·얼음이 녹기 시작한 작은 변화를 느낄 수 있음. 가장 큰 감정 대사는 **하렌의 “잘.했.어.”**로 따로 보호.

## 6. 마을의 관계·대화·연출

- **하렌↔태온 형제애 최우선**: 처음에는 하렌이 안전 때문에 태온 판단을 넘겨짚지만, Main23 마을 주민에게 태온이 통행·보급 판단을 설명하자 형이 여전히 걱정하면서도 짧게 듣는다. 큰 화해/형 최종 칭찬은 보스 후.
- **세린↔미엘 우정**: 여관에서 손·방한 장비·차·장작·마을 주민 걱정을 두고 가벼운 수다. 양쪽 전문성이 Main24 현장 냉기 대응에도 반영된다. **여성 플레이어 추가 한마디 후보**는 별도 대화 선택지로 열 수 있지만 남성 플레이어도 모든 필수 정보/보상·감정선 접근 동등.
- **폴↔미엘 Slow Burn**: 폴이 길/숙소 접근성을 살피면 미엘이 휴식과 체온 대비를 돕는 상호 배려. 미엘의 상처를 폴이 고치거나 과거 연인 대체라는 메시지 금지.
- **미엘 장기 비공개 과거**: Chapter3 Main26 한 번 짧은 암시 가안까지만, 이번 Main23 마을 도착/여관 첫 장면에서 전쟁·약혼·죽음·치유 우선 사건 일절 공개하지 않는다.
- 중요 정보는 대사 TTS 청취가 불가해도 문자·퀘스트 로그·안내 표지로 알 수 있게 한다.
