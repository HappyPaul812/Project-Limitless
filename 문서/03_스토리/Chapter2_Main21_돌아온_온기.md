## 안전 통로 판단 퍼즐과 접근성

- 문자/형태/현장 설명 등으로 단서를 전달하며 색상이나 음성만으로 정답을 구분하지 않는다.
- 잘못 판단하면 근거를 다시 확인하고 재선택 가능. 실패 처벌·추가 전투·자원 차감은 이번에 도입하지 않음.

## 자동 귀환 마차 — 승인 방향 / 아트·구현 대기

Main21 전용 일회성 이동 수단이다. 실제 모든 Field 주행이나 범용 Fast Travel 신규 개발0. 탑승 Yes/No와 짧은 자동 연출·Skip을 제공하고 기존 Save/Continue·Scene Transition을 재사용하는 방향이다. 구체 구현은 [마차 구현 준비 문서](Main21_자동귀환_마차_구현준비_20261010.md)의 상태·도착·입력 복구·저장 실패 검토를 참고한다. 해당 문서의 기술 후보는 구현 완료가 아니다.
