# LIMITLESS 챕터 완료 후 안전지역 공용 편의시설 확대 — 2026-10-13

**상태: 바울 대표 기획 확정 / Unity 구현·QA 미진행 / 각 NPC 외형·위치 미정**

## 바울 대표 확정 규칙

챕터를 완료할수록 **이미 열려 있는 모든 정식 안전지역과 앞으로 추가될 정식 안전지역에서** 해당 서비스를 편하게 이용할 수 있도록 NPC/서비스를 확대한다. 특정 상점 한 곳을 찾아 장거리 왕복하지 않도록 하는 진행 보상이며, 서비스의 **이용 가능 위치**와 그 안의 **상품 해금·구매 상태**는 별개다.

| 조건 | 모든 안전지역에 확대되는 서비스 | 기존·선행 서비스와의 관계 |
| --- | --- | --- |
| **Chapter 2 완료** | **펫 관련 전체 기존 서비스: 야수 동료 분양 + 보유/장착·교체·관리** | Chapter2에서 이미 접근 가능한 아르벨의 펫 분양/관리 UI·기능을 유지한다. 새 지역을 방문할 필요 없이 이전 거점에서도 같은 기능을 이용한다. |
| **Chapter 3 완료** | **스킬 상점: 신규 스킬 구매 + 기존 스킬 강화판 구매** | **Chapter3 플레이 중에는 최초 스킬 상점에서 구매 가능해야 한다.** Chapter3 완료는 스킬 학습의 최초 해금이 아니라 **모든 안전지역으로의 판매망 확대**다. |

- **정식 안전지역**은 게임에서 실제 SafeZone/거점으로 관리되는 곳을 기준으로 하며, 단순히 몬스터가 없는 통로나 연출 공간을 새 안전지역으로 만들어 수를 늘리지 않는다. 안전지역 목록과 NPC 배치는 실제 Scene/Runtime 확인 후 정의한다.
- 기존 NPC나 동일 서비스를 제공하는 장소는 중복 설치하지 않는다. **이미 보유한 분양/장착/스킬 구매 상태와 같은 서비스 데이터**를 어느 거점에서나 사용한다. 동일 서비스를 거점별 별개 재고·별개 구매 기록으로 만들지 않는다.
- Chapter2 완료는 **Main21 완료에 따른 Chapter2 완료 저장 상태**를 기준으로 확인한다. Chapter3 최종 완료 판정용 Quest/ID는 Chapter3 스토리 정본에서 **후속 확정**하고 임의의 Main 번호·플래그를 만들지 않는다.
- 클리어 전 사용 가능한 기존 서비스는 유지하고, 클리어 직후·다시 방문·Save/Continue·타 슬롯 로드에서도 완료 상태를 재평가해 **다른 완료 단계의 서비스가 잘못 열리지 않도록** 한다.
- **야수 동료는 사수 전용**이며 분양소가 모든 거점에 있어도 직업 제한·몬스터 승리/발견 해금·분양100탈렌트·보유·장착 데이터는 그대로다. 정식으로 없는 훈련·부활·펫 업그레이드 메뉴를 '펫 관련 서비스 전체'라는 표현만으로 추가하지 않는다. 다른 직업일 때 UI 접근·안내 방식은 구현 전 검토한다.
- **스킬 상점**은 시작 스킬3개/직업을 제외한 신규·강화 스킬을 **저렴하게 탈렌트로 구매**하는 기존 확정 정책을 따른다. 구매는 캐릭터별 습득 기록에 반영하고 안전지역별 반복 결제는 없다. 새 스킬 습득 후 전투 밖 장착·해제는 무료, 활성 최대6, 전투 스킬 메뉴2행×3열을 보존한다.
- 상점과 관리 서비스는 **NPC를 실제 배치해 상호작용**하도록 설계하되, 기존 공식 NPC·퀘스트 마커/대화·출입구·충돌·휠체어 동선을 침범하지 않는다. 안전지역마다 같은 UI와 기능을 제공하고 NPC 대사·외형·정확 좌표는 담당 아트/스토리 검토 후 확정한다.

## 구현 및 QA 전제 — 아직 실행 승인 아님

1. 현재 StarterVillage, Arbel과 앞으로 등장할 공식 안전지역의 Scene/Runtime SafeZone 관리와 기존 펫 담당 NPC/상점 서비스를 먼저 조사한다. 이미 존재하는 서비스는 유지한다.
2. Chapter2 Main21 완료 상태와 Continue를 확인한 뒤 조건부 펫 분양·관리 NPC를 추가·활성화한다. 같은 SafeZone 안에 2개씩 중복 생성하지 않는다.
3. Chapter3 중 최초 스킬 상점 접근 시점과 Chapter3 완료 시점의 **전역 확대**를 분리한다. Chapter3 진행용 스킬 구매를 엔딩 뒤로 잠그지 않는다.
4. Chapter2 미완료 / Chapter2 완료·Chapter3 미완료 / Chapter3 완료의 **세 저장 상태** 및 각 기존·신규 안전지역에서 NPC 중복0, 서비스 구매/소유/장착 일치, Save/Continue, 동료·파티·펫/경제 값 보존을 QA한다.
5. 기존 상점과 펫 분양 UI, Quest 진행, Scene 이동, Collider, 장애인 접근성, 키보드·패드·마우스 조작 검증. 원본 dirty checkout·사용자 Save·현재 승인 아트·TTS/BGM을 변경하지 않고 Codex 별도 worktree/브랜치에서 비포커스 검증한다.

**미정:** Chapter3 마지막 Quest 완료 ID, 각 안전지역 공식 범위/목록, NPC 수·위치·초상·대사, 상점 명칭·상품 개별 가격, 학습 소유권·UI 구현 세부. 이 문서는 기획 확정이고 실제 코드/Scene/아트 생성이나 GitHub main 병합 지시가 아니다.
