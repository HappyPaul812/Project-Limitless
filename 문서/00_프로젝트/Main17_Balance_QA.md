# Main17 Balance QA

2026-10-06. 생산 Battle Controller의 실제 행동·상태·피해·승리·복귀 경로로 측정했다. 실물 입력이나 최적 전략을 재현하는 시험은 아니다.

## 레벨 근거

LOCAL에는 Main17 도착 권장/강제 레벨의 정식 값이 없다. 현재 필수 진행 Quest01~16의 완료 EXP 합계는495이며 ExperienceProgression.Add(1,0,495)는 **Lv4·EXP95**다. 이것은 일반전/필수전/추가 Quest 보상을 제외한 보수적 산술 하한이며 실제 도착 레벨 예측이 아니다. 반복 사냥/회색 EXP0 규칙 때문에 진행도만으로 유일한 도착 레벨을 계산할 수 없다.

실제 Main17 적은 도마뱀/갑충 모두 Lv12, 직전 망령은 Lv13이다. EXP 판정식 monsterLevel-playerLevel의 노랑 경계(±3), 동격, 녹색(-4)을 사용해 **Low9 / Typical12 / High16**을 대표 위협 구간으로 선택했다. 이 값은 게임 권장 레벨을 새로 확정한 것이 아니다. 추가 **Lv4 하한**을 검사해 적 레벨만 근거로 저성장 플레이어를 누락하지 않았다. 최종 5Job×4레벨×2조우=40회.

## 표본 정책

각 전투는 새 격리 Session/전체 HP·MP/Player 전열·세린 후열·미엘 후열의 저장3인 편성으로 시작했다. 동료는 현재 생산 코드의 고정 참가자 수치·Lv1 기반 보조 성장 계산을 유지하며 플레이어 레벨로 자동 올리지 않는다. 기본 공격으로 실제 대상 선택을 완료하고, 아군 HP가35% 미만이면 실제 Item 메뉴에서 회복약(HP30)을 사용한다. 각 표본에 보유3개를 준비했으며 무료/무제한 회복을 주입하지 않았다. 공격/피해/화상/갑각/행동 순서/Beast는 생산 Controller를 그대로 사용한다. timeScale6은 연출/대기만 빨리 진행하고 능력치·행동 수·상태 수명을 변경하지 않는다. 실물 키보드/패드 입력은 사용하지 않았다.

Seconds는 가속 실행의 실제 경과 시간이며 실제 플레이 시간 추정에 사용하지 않는다. AllyActions/EnemyActions는 관찰된 행동 차례 진입 수다. DamageTaken은 HP 감소 합계(직접+행동 종료 DoT), HealingReceived는 HP 증가 합계다. 표본마다1회 실행이며 **40/40 승리**는 관찰 비율이지 통계적으로 추정한 모든 플레이어의 승률이 아니다. Party/Formation의 모든 조합·장기 연속 사냥은 범위 밖이다.

## 상태·사거리·진형 회귀

실제 일반공격 타깃을 TargetResolver로 선택하고 Controller의 직업 사거리/전후열을 적용했다. 도마뱀의 지열 긁기·울림 예고·다음 행동 균열 돌진/화상, 갑충의 분비액·다음 자기 행동까지 갑각40% 보호를 생산 코드가 실행한다. 전열 Player만 대상으로 만들기 위해 후열을 임의 전열로 옮기지 않았다. 각종 상태/MP/CD와 시작15스킬 상세 규칙은 기존 2차 QA 및 전투 submenu QA의 PASS를 재사용하며 이번 Matrix 승리 수에 다시 합산하지 않는다.

## Main16→Main17 위험 단계

Main16 망령 HP150/Attack27/후열·광역 화상, Main17 도마뱀 HP190/Attack25/전열·예고형170% 돌진과 화상이다. HP는26.7% 증가하지만 Attack은7.4% 낮고 광역 압박도 달라 **모든 난이도 지표가 일률적으로 상승했다고 주장하지 않는다**. 전열 방어와 회복 판단을 요구하는 다른 위험 형태이며 기존 공식 Chapter2 곡선을 그대로 사용한다. 일반 갑충 HP220/Attack22/갑각 보호는 별도 선택 조우다. 신규 Elite·Overheat·작열 감시자를 미리 소모하지 않는다.

대표 범위에서 실제 진행 불가/즉시전멸/수치 결함이 발견되지 않아 **몬스터 Level/HP/Attack/EXP/탈렌트 수치 변경0**. 추가 Job 전용 스킬이나 별도 Beast 시스템을 만들지 않았다.

원시40회: Main17_Balance_Matrix.csv. Runtime 검증 ID: Main17_Closure_Runtime.txt. 보상은 별도 Main17_Reward_Audit.md의 사용자 승인60/50이며 전투 Matrix 종료 보상 수치와 구분한다.
