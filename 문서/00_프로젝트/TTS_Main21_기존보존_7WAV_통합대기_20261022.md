## 4. 나중에 한 번에 Unity 통합할 때 Codex 지시

**착수 트리거:** 사용자(대표)가 세린·태온·하렌을 포함한 이번 더빙 파일 제작/청취 검수를 마친 뒤 **“한 번에 Unity에 넣자”**고 명시 승인하면 착수. 그 전 Unity 스토리 음성 카탈로그·GUID/Meta·씬/Save/Flow 변경 **금지**.

1. **읽기 전용 보호목록 만들기:** 해당 `candidates`의 7개 파일 존재·SHA256·WAV PCM 스펙·길이·정식 원문/화자/ID·사용자 QA를 기록. 원본 바이트 변경/재합성/파일명 덮어쓰기/이동/삭제하지 않는다. 자동화 `Renewal_Voices`에서 이미 있는 Serin/Taeon WAV도 SHA를 기록하고 건너뛴다.
2. **StoryID 매핑:** `Main21_TTS_Manifest_20261010.json`의 Stable ID 정확 일치 확인 후 Unity `StoryVoiceCatalog.asset` 및 오디오 참조/Guid를 정식 구조에 따라 **추가로만** 연결한다. 기존 플레이어 무음, 폴/미엘/레온 기존 챕터 목소리, 기존 소스 GUID/Save/Quest 진행 상태를 보호한다.
3. **7개는 신규 제작 금지**. Voice는 기존 캐스팅 Achird/Sulafat/Orus 유지; 세린/태온은 **기존 챕터 전체**를 새 Voice ID로 일관되게 교체할 계획. 구/신 동일 인물 음색 혼용 배포 금지. 하렌3이 실제 생성·QA 완료된 경우만 해당 통합에 포함.
4. **누락 감사:** Main20·Main21 `VoiceExpected=true` 전체 대사 중 이미 Unity에 있거나 다른 정상 출처 WAV가 있는 것은 KEEP, 진짜 미등록·미존재만 별도 보고. 이번 7개만 보고 “Main20·21 모두 완료”로 오판하지 않는다. 임의 추가 TTS API 호출 없이 보고서부터 제출.
5. **회귀 검증:** Unity 백그라운드 Console/Play Mode, 컷신 대사와 WAV 1:1, 폴/미엘/레온 캐스팅 유지, Main20·21 장면별 Next/Skip/VoiceOnOff/SaveContinue, 난청·시각 장치 Path 분기, 기획 의도/자막 동기 검증. 브랜치 `codex/작업명`과 변경 파일/커밋/승인 여부 보고.
6. **main 통합은 사용자 별도 승인 이후에만.** 현재는 `docs/tts` 문서 기록만, 음성 통합은 `UNITY_PENDING`.

## 4. 나중에 한 번에 Unity 통합할 때 Codex 지시

**착수 트리거:** 사용자(대표)가 세린·태온·하렌을 포함한 이번 더빙 파일 제작/청취 검수를 마친 뒤 **“한 번에 Unity에 넣자”**고 명시 승인하면 착수. 그 전 Unity 스토리 음성 카탈로그·GUID/Meta·씬/Save/Flow 변경 **금지**.

1. **읽기 전용 보호목록 만들기:** 해당 `candidates`의 7개 파일 존재·SHA256·WAV PCM 스펙·길이·정식 원문/화자/ID·사용자 QA를 기록. 원본 바이트 변경/재합성/파일명 덮어쓰기/이동/삭제하지 않는다. 자동화 `Renewal_Voices`에서 이미 있는 Serin/Taeon WAV도 SHA를 기록하고 건너뛴다.
2. **StoryID 매핑:** `Main21_TTS_Manifest_20261010.json`의 Stable ID 정확 일치 확인 후 Unity `StoryVoiceCatalog.asset` 및 오디오 참조/Guid를 정식 구조에 따라 **추가로만** 연결한다. 기존 플레이어 무음, 폴/미엘/레온 기존 챕터 목소리, 기존 소스 GUID/Save/Quest 진행 상태를 보호한다.
3. **7개는 신규 제작 금지**. Voice는 기존 캐스팅 Achird/Sulafat/Orus 유지; 세린/태온은 **기존 챕터 전체**를 새 Voice ID로 일관되게 교체할 계획. 구/신 동일 인물 음색 혼용 배포 금지. 하렌3이 실제 생성·QA 완료된 경우만 해당 통합에 포함.
4. **누락 감사:** Main20·Main21 `VoiceExpected=true` 전체 대사 중 이미 Unity에 있거나 다른 정상 출처 WAV가 있는 것은 KEEP, 진짜 미등록·미존재만 별도 보고. 이번 7개만 보고 “Main20·21 모두 완료”로 오판하지 않는다. 임의 추가 TTS API 호출 없이 보고서부터 제출.
5. **회귀 검증:** Unity 백그라운드 Console/Play Mode, 컷신 대사와 WAV 1:1, 폴/미엘/레온 캐스팅 유지, Main20·21 장면별 Next/Skip/VoiceOnOff/SaveContinue, 난청·시각 장치 Path 분기, 기획 의도/자막 동기 검증. 브랜치 `codex/작업명`과 변경 파일/커밋/승인 여부 보고.
6. **main 통합은 사용자 별도 승인 이후에만.** 현재는 `docs/tts` 문서 기록만, 음성 통합은 `UNITY_PENDING`.
