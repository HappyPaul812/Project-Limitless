## 프로젝트 구조

현재 저장소는 초기 개발 구조를 갖추고 있다.

- `Unity/Client/`: Unity 클라이언트 프로젝트
- `Unity/Client/Assets/`: Unity 에셋 및 프로젝트 리소스
- `Unity/Client/Assets/_Project/`: 프로젝트 고유 에셋의 기본 분류 위치
- `Unity/Client/Assets/Scenes/`: 기존 Unity Scene
- `Unity/Client/Assets/Settings/`: URP 및 Input System 설정
- `Unity/Client/Packages/`: Unity 패키지 구성
- `Unity/Client/ProjectSettings/`: Unity 프로젝트 설정 및 버전 정보
- `문서/`: 기획, 시스템, 접근성, 백로그 등 프로젝트 문서
- `아트/`, `오디오/`: 원본 에셋 관리 공간
- `Server/`: 향후 서버 작업 공간
- `도구/`: 개발 및 콘텐츠 제작 도구

`Assets/_Project/`는 `Art`, `Audio`, `Data`, `Prefabs`, `Scenes`, `Scripts`, `UI`, `Resources`로 구분한다. 각 폴더는 아직 프로젝트 전용 에셋이 없어 추적용 `.gitkeep`만 포함한다.

## 현재 Unity 입력 설정

`Packages/manifest.json`에 `com.unity.inputsystem` 1.20.0이 포함되어 있으며, 프로젝트 설정의 `activeInputHandler`는 Input System 사용 상태(값 `1`)이다. 기존 설정을 유지하며 이번 작업에서는 패키지나 입력 설정을 변경하지 않는다.

## Scene 상태

기존 Scene은 `Assets/Scenes/SampleScene.unity`와 URP 템플릿용 `Assets/Settings/Scenes/URP2DSceneTemplate.unity`가 있다. `Bootstrap.unity`는 Unity Editor를 통해 생성해야 하므로 이 작업에서 빈 파일로 만들지 않았다.
