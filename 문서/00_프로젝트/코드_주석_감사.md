# 프로젝트 C# 설명 주석 감사 (2026-09-24)

범위는 `Unity/Client/Assets/_Project/Scripts/`의 프로젝트 전용 C#이다. ThirdParty, Packages, Library, Temp와 자동 생성 파일은 제외했다. 이번 작업은 설명만 보강했고 전투·저장·퀘스트 동작은 변경하지 않았다.

| 분류 | 확인한 대표 파일 | 판단과 조치 |
|---|---|---|
| 설명이 충분함 | `BattleSkillSystem.cs`, `BattleCore.cs`, `SceneTransitionService.cs`, `DialoguePresenter.cs` | 대상·상태·방어 계산, Scene 전환, 대화 Modal의 이유와 경계가 이미 주석으로 설명되어 유지 |
| 핵심이나 일부 연결 설명 부족 | `QuestService.cs`, `GameSaveService.cs`, `CompanionRosterService.cs`, `PathCombatTraitRuntime.cs`, `QuestNavigationPresenter.cs` | 목표 순서, 저장/복원, 동료 ID 검증, 길 상태 소비, 추적 ID와 화면 좌표 연결에 한국어 주석 보강 |
| 후속 점검 가치가 큼 | 대형 `BattleSceneController.cs`, 개별 Main Quest Field Flow와 Editor 감사 코드 | 화면 연출 및 Scene별 분기는 범위가 넓어 이번에는 동작 변경 없이 보존. 이후 해당 기능을 수정할 때 연결 주석을 함께 점검 |

코드로 확인한 현재 상태와 문서의 차이는 [스킬 정본](../06_스킬/README.md), [전투 정본](../10_전투/전투시스템.md), [미구현 후보](../06_스킬/미구현_향후_후보.md)에 반영했다. 공식 길 이름은 `마음의 상처의 길`이지만 현재 `05_EmotionalScarPath.asset`의 `displayName`은 `마음의 상처`다. 이번 작업은 기능·Asset 수정 금지 범위이므로 이 표시 데이터의 변경은 별도 작업으로 남긴다.
