# Issue #30 · ColdVFX5 배치 표적 보완 · 2026-11-27

[기획 지시](https://github.com/HappyPaul812/Project-Limitless/issues/30#issuecomment-7210567197) · [v1 검수](Issue30_ColdVFX5_v1_Review_20261127.md)

Unity 6000.6.5f1 백그라운드 Battle에서 승인 보스 336 UI px, 기존 휠체어 캐릭터와 전투 HUD를 렌더했습니다. 승인 Snowroad의 밝은 원본·어두운 틴트에서 기존 크기와 후보를 같은 좌표로 비교했습니다. 실제 배율은 1280×720에서 UI 1단위당 1px입니다. 플레이어의 기존 휠체어 Sprite를 테스트 조우에 사용했으며 Main28 보스 행동을 구현하지 않았습니다.

| 표시 | 비교 | 권고 |
|---|---|---|
| 피해 피격 | 기존 144 중앙 전면과 112/120/128 전면을 비교했습니다. 후보는 Pivot (.68,.48), 대상 중심에서 아래로 10px, 알파 .74입니다. | **112px**. 우측으로 치우친 충격 중심이 대상에 맞고 머리와 바퀴 외곽이 선명합니다. 120/128은 상체와 바퀴 위로 영향이 커집니다. |
| 무피해 도달 | 같은 BreathHit의 01셀을 후면에서 작게 표시했습니다. 최초 84px 후면 시험은 바퀴 뒤에 묻혔습니다. | **92px**, Pivot (.68,.28), 발 기준 아래로 16px, 알파 .62. 전체 피격 시퀀스·피해 숫자 없이 약한 서리 접촉만 표시하는 후보입니다. |
| 동결괴사 KO | 기존 176 중앙 전면과 136/144/152 하단 중앙 후면을 비교했습니다. 후보 Pivot (.50,.12), 발 기준 정렬입니다. | **144px 후면**. 136보다 밝은 설원에서 결정이 잘 보이고 152보다 머리 주위 공간을 확보합니다. 세 후보에서 캐릭터·바퀴가 전면으로 유지됐습니다. |
| 브레스 발사·한기·동상 | 이전 판정과 승인 파일 유지. | 발사 원본 PASS 유지. 한기·동상은 승인 공용 VFX와 HUD를 유지합니다. 동결괴사 1/2중첩도 공용 표시를 유지합니다. |

후면 배치는 대상 Sprite 아래, 모든 VFX는 전투 HUD 아래, 입력 가로채기 비활성으로 시험했습니다. 동결괴사 144 후면을 8셀 125ms 간격, 1회 재생한 뒤 오버레이를 제거했습니다. 검증용 재생은 전투 수치를 건드리지 않았습니다. 제품 연결 시 기존 세 번째 유효 적용의 즉시 KO 이벤트에만 붙이는 후보이며 실제 Main28 상태·KO 연계는 미검증입니다.

변경 대상 16셀은 v1 PNG와 바이트 일치. 신규 원화·제품 코드·수치·상태 계약·Save/UserData 변경 없음. 기존 PASS 전수 재실행 없음. 본편 적용·main 병합·Push 없음.

최종 렌더 종료 코드 0. 92px 무피해 접촉은 양쪽 배경에서 바퀴 아래에만 희미하게 남습니다. 밝은 설원에서는 특히 약하므로 상태 HUD를 판독 기준으로 유지합니다. 기존 Editor Search 시작 예외가 재현됐습니다.
