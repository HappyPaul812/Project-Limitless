## 2026-10-20 최신 — 하렌 첫 대사 수정은 정식 3대사 제작 때

- 사용자 최신 지시: “나중에 하렌 대사 뽑을 때 할꺼니 문서화 해줘”. **하렌 억양 R1 즉시 실행 금지(현재 DEFERRED)**. 기존 준비된 R1 ZIP·실행 명령은 실행 지시가 아닌 제작 참고자료로만 유지.
- `main21_haren_haren_01` **“태온. 너 아직 멀었어.”** — 평서문 하강. `main21_haren_haren_02` **“다친 데는 없고?”** — 의문문. `main21_haren_haren_03` **“그럼 됐어.”** — 평서문 하강. 문장부호/원문/Stable ID 보존.
- 추후 세 대사를 `Alnilam`으로 묶어 제작하되, 각각 별도 1회 요청·청취 QA. 사용자 승인 전 Unity에 혼용·적용 금지. [최신 보류 정본](../../TTS_하렌_평서문_억양_수정R1_20261020.md).


## 2026-10-20 필수 신규 경고 — Voice 성별 역전 사고 재발 방지

**[정식 TTS 사고 보고서 및 3인 리캐스팅](../../TTS_캐스팅_성별역전_음색불일치_사고보고서_및_3인재캐스팅_20261020.md)** 를 다음 제작 이전에 반드시 읽는다.

- **캐스팅 시 공식 제공자 Voice 성별·음색 설명과 캐릭터 설정을 먼저 교차 검증**하고 한국어 실제 대사 1개 이상을 사용자 직접 청취 승인. 구 음성의 “실제 들린 음색”을 Voice ID의 영구적 성별/음질 보증으로 해석하지 않는다.
- 예전 세린 Schedar는 공식 남성, 태온 Gacrux는 공식 여성. 최근 음색 오류는 사용자 직접 청취로 확정됐으나 Google 내부 버그 수정은 **미확정**.
- 사용자 최신 범위는 **하렌 Alnilam(3)→세린 Erinome(67)→태온 Algieba(85)**, 합계155개 현 확정 ID. 공식 데모 “좋네”는 **실제 한국어 WAV 최종 승인 아님**.
- 동일 화자는 처음 챕터부터 끝까지 새 캐스팅 음색으로 통일, 기존 승인/원본 WAV·Meta/GUID·Catalog·Save·HOLD 보호. **DSP/PSOLA 불합격16개 전량 금지**. 신규 사용자 합격 전 임의 Unity 변경 및 다른 캐릭터 전면 재생성 금지.
- 기술 QA(PASS: WAV 포맷·해시·Runtime)와 청취 QA(목소리/발화/캐릭터 일관성)를 반드시 구별. API 오류 원문은 비밀키를 마스킹해 checkpoint에 남기고 성공/실패 횟수 분리. 실제 quota는 key 개수가 아닌 Project+Model 단위 확인.

## 책임·실행
1. 안정적인 **Dialogue ID / 화자 / 원문 / Scene 순서**를 정본과 대조한다. **게임 대사를 TTS 편의로 임의 수정하거나 ID를 재번호화하지 않는다.**
2. 캐릭터별 공식 Voice와 장면별 Style을 분리한다. 세린 등 음색 오류·재제작 대기 건은 최신 QA를 읽고 **승인 없이 목소리를 교체하지 않는다.**
3. quota와 모델/프로젝트, 실제 체크포인트를 확인한다. 현행 정책의 **1 Stable ID = 1 호출 = 1 WAV** 및 실패 즉시 중단·성공본 보존 규칙을 따른다. 키·비밀번호 등 비밀 정보를 GitHub/로그에 쓰지 않는다.
4. WAV와 Manifest·샘플·요청 메타데이터(민감 정보 제외)·음질/발화/원문/화자 정합을 검수한다. **자동 ASR 일치와 사람의 실제 청취 승인은 별개**다.
5. 사용자 청취 승인이 필요한 부분은 상태를 명확히 표기한다. 제작된 WAV를 무단 Unity에 연결하지 않으며 승인 후 **Codex에게 Unity 적용·회귀 검증**을 의뢰한다.
6. 사용자 음성·대사 권리, 서비스 이용조건, 비용/quota, 비밀키 보호를 고려한다.

## 최근 유의
2026-10-12 QA에서는 Main18·19 정상 음성 25개 통합과 **세린 음색 불일치 10개 재제작 대기**를 구분했다. 이 수치는 시작 시 반드시 CURRENT_STATUS와 [후속 QA](../../Main18_19_TTS_Selective_Integration_QA_20261012.md)에서 갱신 여부를 재확인한다. 과거 상태에 고정하지 않는다.

## 납품·후임
Dialogue ID별 목록, 파일 경로/해시, 모델/Voice/Scene Style, 실제 생성 상태, 사람 청취 결과, 오류·재제작 목록, quota 체크포인트, Codex 통합 승인 상태를 정리한다. 인계/TTS_LATEST.md를 갱신한다.

- 인물용 원문에 마침표(.)가 정확히 있어도 생성된 대사는 **의문문 상승 억양**이 나올 수 있음. 하렌 `main21_haren_haren_01` 공식 원문 **`태온. 너 아직 멀었어.`** 수정 금지.
