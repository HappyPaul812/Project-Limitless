# TTS / 캐릭터 더빙 담당 행동요령

## 필수 정본
[정식 음성 제작 정책](../../TTS_음성_제작_정책.md) · [Free Tier quota 운영](../../TTS_FreeTier_Quota_운영_기록.md) · [Story 대사 규칙](../../../03_스토리/Story_대사_지문_작성_규칙.md) · [CURRENT_STATUS](../../CURRENT_STATUS.md) · 관련 챕터 Dialogue/Voice Registry/Manifest/최근 통합 QA. 역사적 제작 이력보다 더 늦은 검수·정식 정책을 우선한다.

## 책임·실행
1. 안정적인 **Dialogue ID / 화자 / 원문 / Scene 순서**를 정본과 대조한다. **게임 대사를 TTS 편의로 임의 수정하거나 ID를 재번호화하지 않는다.**
2. 캐릭터별 공식 Voice와 장면별 Style을 분리한다. 세린 등 음색 오류·재제작 대기 건은 최신 QA를 읽고 **승인 없이 목소리를 교체하지 않는다.**
3. quota와 모델/프로젝트, 실제 체크포인트를 확인한다. 현행 정책의 **1 Stable ID = 1 호출 = 1 WAV** 및 실패 즉시 중단·성공본 보존 규칙을 따른다. 키·비밀번호 등 비밀 정보를 GitHub/로그에 쓰지 않는다.
4. WAV와 Manifest·샘플·요청 메타데이터(민감 정보 제외)·음질/발화/원문/화자 정합을 검수한다. **자동 ASR 일치와 사람의 실제 청취 승인은 별개**다.
5. 사용자 청취 승인이 필요한 부분은 상태를 명확히 표기한다. 제작된 WAV를 무단 Unity에 연결하지 않으며 승인 후 **Codex에게 Unity 적용·회귀 검증**을 의뢰한다.
6. 사용자 음성·대사 권리, 서비스 이용조건, 비용/quota, 비밀키 보호를 고려한다.

## 최근 유의
2026-10-12 QA에서는 Main18·19 정상 음성 25개 통합과 **세린 음색 불일치 10개 재제작 대기**를 구분했다. 이 수치는 시작 시 반드시 CURRENT_STATUS와 [후속 QA](../../Main18_19_TTS_Selective_Integration_QA_20261012.md)에서 갱신 여부를 재확인한다. 과거 상태에 고정하지 않는다.

## 납품·후임
Dialogue ID별 목록, 파일 경로/해시, 모델/Voice/Scene Style, 실제 생성 상태, 사람 청취 결과, 오류·재제작 목록, quota 체크포인트, Codex 통합 승인 상태를 정리한다. 인계/TTS_LATEST.md를 갱신한다.
