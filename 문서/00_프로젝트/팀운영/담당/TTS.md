## 필수 공통 자동화 운영 표준 (2026-10-21)

- 다음에 **새 캐릭터·다른 TTS 모델·다른 챕터의 다중 키 자동 생성**을 제작할 때 반드시 [TTS 공통 다중 프로젝트 Quota·429 Failover·체크포인트 운영 표준](../../TTS_공통_다중프로젝트_할당량_429자동전환_체크포인트_운영표준_20261021.md)을 먼저 읽는다.
- **실제 Google 프로젝트 ID 소속 확인이 최우선**이다. 같은 프로젝트의 다른 API 키로 요청 제한을 우회하지 않는다. 프로젝트/모델/태평양 일자별 안전 예산은 실제 무료·과금 상태와 외부 사용량을 고려하여 지정한다. 세린·태온 당시의 **40회/프로젝트당 안전10회는 운영 예시**이지 범용 고정 quota가 아니다.
- HTTP429면 정확한 RPM·TPM·RPD 원인은 서버 정보 확인 전 **미확정**. 당일 실패 프로젝트 그룹을 격리하고 다른 **검증된 독립 그룹**에만 전환. 전환 불가·다른 오류·결과불명이라면 안전 중단. 기존 WAV·비밀키·장부·HOLD/LOCK 보존.
- 신규 캐릭터는 전용 manifest/Voice/Style/폴더/대사 원문을 정확 정본으로 만들고, 샘플 청취 승인 후 한 대사당 한 최종 WAV를 생성. 요청마다 전송 전 ATTEMPT와 성공/실패를 기록하고 재실행 시 SHA 검증 후 중복 생성 금지. 기존 `Renewal_Auto_TTS_Failover_v2.py`는 **세린·태온 특화판**, 범용 엔진 완성본이 아님.
- 중요 실사용 검증: 2026-10-21 KEY3 429 후 KEY4로 Main20 세린 성공, 39/40에서 안전 CAP 종료, READY 세린63·태온1. 이 수치는 사람 청취 QA 최종 합격 수가 아니다. 하렌 **즉시 재생성 보류** 지시 계속 유지.

## 2026-10-20 필수 신규 경고 — Voice 성별 역전 사고 재발 방지

**[정식 TTS 사고 보고서 및 3인 리캐스팅](../../TTS_캐스팅_성별역전_음색불일치_사고보고서_및_3인재캐스팅_20261020.md)** 를 다음 제작 이전에 반드시 읽는다.

## 책임·실행
1. 안정적인 **Dialogue ID / 화자 / 원문 / Scene 순서**를 정본과 대조한다. **게임 대사를 TTS 편의로 임의 수정하거나 ID를 재번호화하지 않는다.**
2. 캐릭터별 공식 Voice와 장면별 Style을 분리한다. 세린 등 음색 오류·재제작 대기 건은 최신 QA를 읽고 **승인 없이 목소리를 교체하지 않는다.**
3. quota와 모델/프로젝트, 실제 체크포인트를 확인한다. 현행 정책의 **1 Stable ID = 1 호출 = 1 WAV** 및 실패 즉시 중단·성공본 보존 규칙을 따른다. 키·비밀번호 등 비밀 정보를 GitHub/로그에 쓰지 않는다.
4. WAV와 Manifest·샘플·요청 메타데이터(민감 정보 제외)·음질/발화/원문/화자 정합을 검수한다. **자동 ASR 일치와 사람의 실제 청취 승인은 별개**다.
5. 사용자 청취 승인이 필요한 부분은 상태를 명확히 표기한다. 제작된 WAV를 무단 Unity에 연결하지 않으며 승인 후 **Codex에게 Unity 적용·회귀 검증**을 의뢰한다.
6. 사용자 음성·대사 권리, 서비스 이용조건, 비용/quota, 비밀키 보호를 고려한다.
