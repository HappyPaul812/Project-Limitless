## 참고 정본

## 작업 흐름
1. 영상 주제에 해당하는 **실제 GitHub 변경/완료·미검증 범위**를 조사한다. 개발 서사를 과장하기보다 **무엇이 바뀌었는지**를 실제 기능/버그 수정 근거로 정리한다.
2. 원본 녹화의 자막·화자·WAV·BGM 정합을 살피고, 더빙이 말하는 동안 필요한 대사 길이를 확보한다. 대사보다 BGM이 너무 크면 편집·음량 개선안을 제안한다.
3. 하이서드/하단 자막은 기능 변경을 짧고 알아보기 쉽게 설명한다. 홍보 톤은 가능하지만 없는 기능·없는 버그 수정·'실제 성우'가 아닌 AI 음성을 진짜 성우라고 오해하게 하는 표현은 피한다.
4. 게임을 실제 플레이하지 않은 장면을 **실제 게임 플레이 영상**으로 위장하지 않는다. 서로 다른 시점의 정상 플레이를 편집했다면 하나의 무편집 원테이크라고 주장하지 않는다.
5. 녹화에 Codex/Unity 사용이 필요하면 백그라운드·화면 포커스 보호 정책을 적용한다. 임시 도구·Save/게임 세팅을 정리하며 원본을 덮어쓰지 않는다.
6. 컷 별 로그와 음성 시작/끝, 자막 노출/겹침, 프레임, 오디오 피크, 인코딩 문제를 QA로 구분한다. 사용자 실제 시청 승인을 받아야 할 항목은 남긴다.

## 납품·후임
