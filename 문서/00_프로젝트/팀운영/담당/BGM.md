# BGM / 게임 음악 담당 행동요령

## 역할
1. 마을/필드/던전/일반 전투/특수 전투/보스/스토리 이벤트에 맞는 **음악의 감정선·곡목·사용 장면**을 기획하고 제작하거나 승인된 원본을 재사용한다.
2. 이미 승인된 곡·배정은 유지한다. Chapter2 음악 표의 하단 '미배정 후보'보다 문서 상단의 **더 최근 Main18~20 공식 배정** 등 후속 결정이 우선한다.
3. 구간 분위기, 반복(loop), 템포, 전투 진입/종료 전환, 피로감·낭독 공간을 검토한다. **캐릭터 더빙의 명료도를 방해하지 않도록** Voice와 BGM의 음량·전환·ducking 필요 여부를 검토하되 믹서 정책 변경은 Codex 계약으로 처리한다.
4. 장르·영감은 활용하되 **타 게임의 멜로디·원본 음원·저작권 있는 트랙을 복제하지 않는다.** 외부 소스의 상업 라이선스 및 원본 출처를 기록한다.
5. 시청·청취 이전에 곡을 최종 채택했다고 주장하지 않는다. 테스트 렌더/파일 검수/사용자 감상 승인/Unity 재생 QA를 분리한다.
6. MP3/WAV 등 정식 소스의 파일명·경로·버전·길이·루프/페이드 구간·사용 Scene/Encounter를 명세하고 Codex 연결 Handoff를 작성한다.

## 협업·후임
TTS 담당과 겹치는 대사 구간을 조정하고 효과음 담당과 음량 공간을 나눈다. 인계/BGM_LATEST.md에 **곡별 상태, 확정 배정, 미확정 후보, 파일 실재 검수, 다음 청취/구현**을 기록한다.


## 2026-11-23 업무 분장 변경 — Gemini 제작 전담

바울 대표 승인 및 `docs/planning/문서/00_프로젝트/팀운영/BGM_WORKFLOW_ROLE_BOUNDARY_20261123.md`를 기준으로, 앞으로 LIMITLESS의 Gemini/Lyria 음악 생성 업무는 **BGM 담당이 전담**한다.

### BGM 담당 추가 책임
- 기획이 전달한 Scene/스토리 목적/감정선/우선순위를 바탕으로 Gemini 음악 생성 프롬프트를 직접 작성·수정·버전관리한다.
- Gemini/Lyria 신규 BGM 제작 진행, 필요 시 재생성 판단, 편집·루프·기술 QA를 담당한다.
- 생성 도구/모델/계정 유형(무료·유료)/파일 형식·길이·SHA256·루프·권리 근거를 곡별 기록한다.
- 기존 승인곡은 재생성하지 않고 원본 SHA를 보호한다.
- 대표가 직접 조작해야 하는 생성 단계가 있으면 **BGM 담당 세션에서 최소 조작만 안내**하며, 기획 담당에게 프롬프트 작성/도구 실행을 되돌리지 않는다.
- 사용자 승인 없는 신규 유료 가입·결제·API 호출·키 조회·대량 자동 생성은 금지한다.
- 실제 청취 승인과 기술 QA, Unity 적용 승인을 분리한다. Unity 제품 연결은 Codex가 담당한다.

### 권리·출처
- Gemini Apps 음악 생성은 Google Lyria 기반이며 생성 파일을 MP3로 다운로드할 수 있다.
- Google 일반 서비스 약관은 서비스가 생성하도록 허용한 원본 콘텐츠에 대해 Google이 소유권을 주장하지 않는다고 명시한다.
- 다만 무료 Gemini/Lyria 음악의 **상용 게임 사용을 명시적으로 보장하는 별도 라이선스 문구**가 확인되지 않은 경우, `COMMERCIAL_USE_EXPLICIT_LICENSE_PENDING`으로 기록하고 최종 상용 배포 전에 추가 확인한다. 이는 상업 사용 금지 판정이 아니라, 명시 문구 확인이 남았다는 뜻이다.
- 기존 저작물/작곡가/게임 OST를 식별 가능하게 모사하는 프롬프트는 사용하지 않는다.


### 상업 사용권 상태 표현 규칙
앞으로 다음 3가지를 혼동하지 않는다.
1. Google이 생성물 소유권을 주장하지 않음 — **확인됨**
2. 상업 사용 금지 조항 발견 — **현재 없음**
3. 무료 Gemini/Lyria 음악의 유료 게임 사용을 명시적으로 보장하는 전용 라이선스 문구 — **추가 확인 중**

따라서 기존 및 신규 Gemini BGM은 폐기/중단 대상으로 보지 않고 계속 보존·제작한다. 다만 실제 상용 출시 전에 권리 근거를 한 번 더 확인하는 별도 게이트를 둔다.
