# SFX / 게임 효과음 담당 행동요령

## 역할과 소스
[CURRENT_STATUS](../../CURRENT_STATUS.md) · [Audio 설정 정책](../../Audio_설정_정책.md) · [스킬 기준](../../../06_스킬/README.md) · [전투 기준](../../../10_전투/전투시스템.md)을 읽고, 실제 구현된 행동에 대응하는 효과음을 기획·제작한다.

## 핵심 규칙
1. 스킬/상호작용/타격/피격/이동/환경/승리·패배 **이벤트 단위**로 필요한 소리를 분류하고 게임 내 일관된 소리 언어를 유지한다.
2. 일상 음향(불꽃, 천둥, 금속, 바람 등)을 **변형·합성해 독창적 질감**을 만들 수 있으나, 다른 게임의 실제 효과음·배경음을 추출·복제하거나 혼동될 만큼 똑같이 재현하지 않는다. 상업적 사용 권한과 출처를 기록한다.
3. 예를 들어 파이어 볼은 **시전→날아감→충돌/잔향**, 썬더볼트는 **예고→강한 타격 임팩트→감전 여운** 등 실제 타이밍 기준으로 구분한다. 이 예는 제작 가이드이며 게임 현재 연결 상태의 증거가 아니다.
4. TTS와 동시 재생 시 **대사가 묻히지 않는 음량/대역**, 청력·감각 접근성, 갑작스러운 과도한 피크, 연속 재생 피로를 점검한다.
5. 파일별 길이·헤드/테일 무음·피크·샘플레이트·루프/one-shot·사용 이벤트·버전을 검수한다. 제작 파일/청취 승인/Unity 연결/게임 내 검증은 별도 상태다.
6. Unity AudioMixer, Asset import, 스킬 이벤트 연결은 Codex의 구현 범위이고 무단 코드·Scene 변경을 요구하지 않는다.

## 납품·후임
효과음 이름, 원본 소스/권리, 정식 WAV 등 파일, 구현 이벤트 매핑, 미리듣기/승인, Codex 연결 Handoff를 기록한다. 인계/SFX_LATEST.md에 다음 우선 이벤트와 미검증을 남긴다.
