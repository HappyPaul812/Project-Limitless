## 3. 단회 엘리트 조우 완료 키

저장 슬롯 안에서 승인된 **고정 조우 1건**을 불변 키 1개로 식별합니다. 기존 `BattleSceneFlow.cs`의 `BattleEncounterContext.StableEncounterId`는 지정 스토리/일부 스폰만 해석하고 기타 스폰은 빈 문자열을 반환합니다. 빙각 수호체용 키의 실제 문자열은 공식 조우 등록 시 확정합니다.

- **A. 기존 stable encounter ID 재사용(권장)**. 공식 조우에 고유하고 변경 금지인 ID가 부여되는 경우 사용합니다. 장면 이동·표시명 개명 이후에도 동일 값을 유지합니다.
- **B. 별도 영속 완료 ID 승인**. 공식 조우 ID의 안정성을 보장할 수 없는 경우에만, 저장용 ID를 명시 배정하고 조우에 매핑합니다. 기존 Quest ID, MonsterId, 좌표, 현재의 메모리 기반 비재생성 키와의 자동 결합은 피합니다.

승리 시 완료와 보상 상태를 함께 기록합니다. `수령 대기`와 `수령 완료`는 모두 처치 완료로 취급하여 조우를 다시 열지 않습니다. 패배·도주에는 기록이 생기지 않습니다. 조우 진입과 승리 보상 적용 직전 모두 슬롯의 키를 확인합니다.
