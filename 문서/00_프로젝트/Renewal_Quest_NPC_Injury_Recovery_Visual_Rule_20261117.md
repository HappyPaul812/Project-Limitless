# LIMITLESS / Chapter 1·2 리뉴얼 / 퀘스트 등장 NPC 상태·부상 외형 표현 공통 규칙

> 바울 대표 직접 결정 (2026-11-17): “시작마을 일반 주민 정리가 끝났으니, 이제 퀘스트에 등장하는 NPC는 다친 설정이라면 그 상태가 외형에 자연스럽게 반영되어야 한다.”

## 적용 대상·선행 조건
- **앞으로 제작하는 Chapter 1·2 퀘스트용 NPC의 오리지널 정지 1포즈 후보에 적용**. 일반 주민과 달리 대사·퀘스트의 도움이 필요한 이유가 외형에서 어느 정도 읽히도록 한다.
- **퀘스트 캐논 먼저 확인**: 관련 Issue, 기획 최신 인계, Quest·StableID·NPC 대사/상호작용 계약을 읽고 **부상/회복 상태가 명시되거나 확인된 경우에만** 그에 맞는 표현을 적용. **확정되지 않은 부상·장애·원인·증상·직업·퀘스트/서사를 임의 창작하거나 장애 자체를 ‘도움이 필요한 이유’로 묘사하지 않는다.** 기존 승인 NPC를 새 규칙 때문에 재작화하지 않는다.
- 기본 화풍: LIMITLESS의 기존 승인 NPC 픽셀 밀도/굵기·명암·시점·월드스케일·발 접지·접근성을 유지하며, 얼굴형/눈매/머리·체형·복장과 생활 소품 다양성 규칙을 함께 준수한다. 정지형 캐릭터의 앉은 자세·의자·부목 등은 기존 Collider/월드 스케일과 충돌할 수 있으므로 **실제 게임 적용 이전 Codex 별도 검증**.

## 상태별 오리지널 시각 표현
| 이미 확정된 퀘스트 상태 | 자연스러운 외형 표현 예시(무조건 다 넣지 않음) | 피해야 할 표현 |
|---|---|---|
| 다리 부상/이동 제한 | 편안한 체중 분배, 지팡이·목발·난간 기대기, 의자에 앉기, 발을 쉬게 한 자세 | 피 튀김, 과장된 절규, 다친 부위를 기괴하게 확대 |
| 팔·손 부상 | 팔걸이, 소박한 부목·붕대, 한 팔을 몸쪽에 두는 자세, 반대 손으로 작은 생활 소품 들기 | 어색한 관절·손가락, 극적인 전투 피해 연출 |
| 치료·회복 중 | 의자/침상, 담요, 휴식하는 몸짓, 천천히 몸을 지탱하는 안정된 자세 | 무기력·비참함만 강조하는 연출 |
| 긴장·피곤·조심스러운 상태 | 살짝 긴장된 눈매, 피로한 눈꺼풀, 경계하는 몸짓, 작은 표정 변화 | 모든 퀘스트 NPC를 동일한 울상/눈물·고통 얼굴로 통일 |

- **선택 원칙**: 해당 퀘스트 설정과 일치하는 **가장 적은 수의 시각 단서**로 충분히 읽히게 한다. 붕대·지팡이·부목 등을 부상 표현의 필수 표지로 강제하지 않는다. 사용 가능한 보조기구는 결핍·불쌍함의 상징이 아니라 삶의 일상적인 도구로 표현한다.
- **존엄 우선**: 과한 피·상처·고어·고통의 과장, 구걸/불쌍함을 연상시키는 구도, 장애·부상을 악역/비극·무능과 자동 연결하는 묘사 금지. 긴장·피곤함·회복 중·조심스러움·안도 등 인물별 서로 다른 표정과 자율성을 유지한다.
- 기존 캐릭터들과 **동일한 가족 얼굴처럼 보이지 않도록** 얼굴형·눈매·머리카락·체형 실루엣·의상 색면·소품/자세를 차별화한다. 참고 규칙: [2026-11-17 시작마을 NPC 외형 다양성](Renewal_StarterVillage_NPC_Visual_Diversity_Rule_20261117.md).

## 제작·제출·검수
1. **퀘스트 관련 식별자 확인**: NPC·StableID·등장 씬/기존 대사·도움이 필요한 이유/명시된 상태를 기획 문서에서 확인. 명시되지 않으면 **`QUEST_STATE_NOT_VERIFIED`**로 보류하고 임의 연출하지 않는다.
2. **신규 후보 미술만 제작**: 중복 승인 원화 검사 후 별도 발주 범위에 맞춰 512×512 RGBA 투명 정지 1포즈, 128/40 실제 크기 축소. 기존 PNG·승인 시안 바이트 그대로 보호. 초상화·애니메이션/다방향 제작 금지.
3. **실제 원본 기반 비교판**: 512/128/40 동월드배율에서 기승인 NPC와 대조하고 “**어떤 상태인지**”, “**퀘스트와 어떻게 연결되는지**”, “**다른 NPC와 얼굴·실루엣·색/소품이 어떻게 다른지**”를 각각 짧게 표기. 이미지 검색 결과나 무관 인물 이미지 대용 금지. 40px에서 상태·발 접지·눈에 띄는 도구 확인; 작은 세부가 안 보이면 그 한계를 기재.
4. **납품 보증**: 후보 PNG·비교판/Preview·SourceDeclaration·Manifest(비순환)·SHA256SUMS·ZIP CRC/ZIP SHA256, 브랜치/commit/사용자 승인 여부와 `OFFLINE_NOT_UNITY_VERIFIED` 상태를 분리 기록.
5. **승인 게이트**: `USER_ART_REVIEW_PENDING / NOT_UNITY_APPLIED`. 사용자 미술 승인 전 Unity Import·Scene/Prefab/Resources 매핑 변경, 초상화/애니메이션 금지. 승인 후에도 Codex가 자세/발 접지/좌표·Nameplate/Collider·입력·퀘스트 동선·Save 회귀를 최소 범위에서 검증하고 **별도 게임 적용 승인**을 받을 것.
