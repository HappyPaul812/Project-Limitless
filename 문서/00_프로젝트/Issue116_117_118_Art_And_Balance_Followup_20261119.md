## Unity 6000.6.5f1 라이선스 직접 진단

- 기존 실패 로그에서 Editor가 라이선스 클라이언트 프로세스를 시작했으나 `LicenseClient-windows` 채널 연결이 거부됐고 약 60초 대기 후 재시도했습니다. 제한 환경의 `unity license status`는 `LICENSING_CLIENT_UNAVAILABLE`였습니다. 동일 읽기 전용 조회를 승인된 일반 실행 환경에서 실행하자 성공했습니다. 같은 환경의 6000.6.5f1 격리 배치 로그에서도 IPC 연결, Unity Personal 권한 조회 및 라이선스 갱신 성공을 확인했습니다. 직접 관찰된 원인은 제한 실행 환경에서의 로컬 IPC 접근 실패입니다. 차단한 개별 OS 규칙은 식별하지 못했습니다. CLI 업데이트 확인도 동일 제한 환경에서 DNS ENOTFOUND였습니다.
- 기존 격리 프로젝트는 라이선스를 통과한 뒤 100초 제한 내 검사 진입에 도달하지 못했습니다. 최소 프로젝트에서도 라이선스와 Input System·Physics 초기화 로그까지 확인했습니다. 최소 프로젝트는 Package Manager IPC 연결과 Asset Database 재빌드·Unity Data Store 시작까지 진행했으나 120초 내 검사 메서드 실행 표식이 없었습니다. 두 배치는 이번에 시작한 격리 프로세스만 시간 제한에서 종료했습니다. 라이선스 이후 시작 지연의 원인은 미확정입니다. 권한 조회와 실행 완료를 서로 다른 판정으로 유지합니다. 원본 Unity Hub 인증 및 라이선스 설정, 게임 Editor 창은 조작하지 않았습니다. 로그 원문은 로컬 Temp에 두고 라이선스 식별자가 들어간 원문을 커밋하지 않았습니다.
- 검토한 Unity 스킬 문서는 `unity-cli.md`, `common-workflows.md`, `auth-license-cloud.md`입니다. [Unity 로그 위치](https://docs.unity.com/en-us/engine/6000.0/manual/get-started/project-configuration/log-files)

## Lv19~21 3인 폭군전 — 승인 수치 시뮬레이션

원본 직업 성장 계산 함수와 기존 동료 기본값 및 성장 산식을 재사용했습니다. 기존 기본기와 정조준 160%, 습격 180%, 난도 150%, 기세 2 회심 160%, 파이어 볼 170%와 화상, 치유의 빛 35%/MP6을 사용한 정책 모형입니다.
