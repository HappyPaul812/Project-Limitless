# 외부 에셋

## Kenney RPG Base

- 에셋명: Kenney RPG Base
- 제작자: Kenney Vleugels (Kenney)
- 프로젝트 내 위치: `Unity/Client/Assets/ThirdParty/Kenney/RPGBase/`
- 사용 목적: 일반적인 마을 및 필드 환경 그래픽

## 라이선스

포함된 `license.txt` 기준 라이선스는 **CC0 (Creative Commons Zero 1.0)** 이다.

원문은 개인 및 상업 프로젝트에서 사용 가능하며, Kenney 또는 kenney.nl 표기는 선택 사항이고 의무가 아니라고 명시한다.

## 원본 보호

`Assets/ThirdParty/`의 PNG 원본은 수정하지 않는다. Unity Import Settings 변경은 가능하지만, 프로젝트 전용으로 편집한 에셋이 필요하면 `Assets/_Project/` 아래에 복사하여 사용한다.

## Basic Hand-Drawn Tileset and Asset Pack

- 에셋명: Basic Hand-Drawn Tileset and Asset Pack (Top-Down 128x128)
- 제작자: Schwarnhild
- 프로젝트 내 위치: `Unity/Client/Assets/ThirdParty/Schwarnhild/BasicHandDrawn/`
- 사용 목적: Starter Village의 지면, 길, 건물, 나무, 덤불, 바위, 울타리
- 라이선스: 포함된 `Info_and_License.txt` 기준으로 상업·비상업 프로젝트 사용 및 수정이 가능하다. 수정 여부와 관계없이 재배포·재판매는 금지되며, 사용 시 제작자 표기를 요청한다.

## Essential RPG

- 에셋명: Essential RPG
- 제작자: Xariami
- 프로젝트 내 위치: `Unity/Client/Assets/ThirdParty/Xariami/EssentialRPG/`
- 사용 목적: Starter Village의 상자, 통, 캠프파이어 등 보조 소품
- 라이선스: 제공 폴더 안에 라이선스 문서가 없어 현재 원본 배포처의 라이선스 확인이 필요하다. 확인 전에는 재배포하지 않는다.
