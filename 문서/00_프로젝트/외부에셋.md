# 외부 에셋

## Game-icons.net Path 공식 아이콘

- 다운로드 위치: `F:/Downloads/`. `%USERPROFILE%/Downloads`와 Windows 등록 경로는 현재 존재하지 않아 실제 폴더를 찾아 사용했다.
- White 원본: `game-icons.net.png.zip`, Black 원본: `game-icons.net.png (1).zip`.
- 압축 내부 공통 경로: `icons/{색상}/transparent/1x1/{아래 경로}`. White 색상은 `ffffff`, Black은 `000000`이다.

| 길 | 원본 경로 끝부분 | 저작자 |
|---|---|---|
| 마음의 상처 | `delapouite/heart-shield.png` | Delapouite |
| 청각의 길 | `skoll/sound-waves.png` | Skoll |
| 시각의 길 | `delapouite/eye-target.png` | Delapouite |
| 지체의 길 | `lorc/cog.png` | Lorc |
| 지적의 길 | `delapouite/mesh-network.png` | Delapouite |

- 출처: https://game-icons.net . 저작자와 라이선스는 압축의 `icons/license.txt` 및 저작자별 폴더로 확인했다. 이 다섯 아이콘은 원본 문서의 Creative Commons 3.0 BY 대상이다.
- 저작자 표시: **Icons made by Delapouite, Skoll and Lorc — Game-icons.net, Creative Commons 3.0 BY.**
- 원본 라이선스 보존: `Unity/Client/Assets/ThirdParty/GameIconsNet/license.txt`. 두 압축의 라이선스는 동일하며 한 부만 보관한다.
- PNG 10개만 `Unity/Client/Assets/ThirdParty/GameIconsNet/Path/White/`와 `Black/`에 파일명 그대로 복사했다. PNG 바이트는 변경하지 않았다. 원본 압축과 다른 다운로드 에셋은 그대로 유지한다.
- 기본 연결은 짙은 남색 카드·상세 팝업에서 읽기 쉬운 White다. Black은 보관용이다. 512×512 Sprite/Single, Bilinear, Clamp, 무압축, Mipmap Off, Alpha Is Transparency 설정을 사용한다.

## Kenney RPG Base

- 에셋명: Kenney RPG Base
- 제작자: Kenney Vleugels (Kenney)
- 프로젝트 내 위치: `Unity/Client/Assets/ThirdParty/Kenney/RPGBase/`
- 사용 목적: 일반적인 마을 및 필드 환경 그래픽

## 라이선스

포함된 `license.txt` 기준 라이선스는 **CC0 (Creative Commons Zero 1.0)** 이다.

원문은 개인 및 상업 프로젝트에서 사용 가능하며, Kenney 또는 kenney.nl 표기는 선택 사항이고 의무가 아니라고 명시한다.

## 원본 보호

`Assets/ThirdParty/`의 PNG 원본은 수정하지 않는다. Unity Import Settings 변경은 가능하지만, 프로젝트 전용으로 편집한 에셋이 필요하면 `Assets/_Project/` 아래에 복사하여 사용한다.

- 제작자: Schwarnhild
- 프로젝트 내 위치: `Unity/Client/Assets/ThirdParty/Schwarnhild/BasicHandDrawn/`
