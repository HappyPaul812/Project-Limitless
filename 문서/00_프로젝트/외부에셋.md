# 외부 에셋

## Kenney RPG Base

- 에셋명: Kenney RPG Base
- 제작자: Kenney Vleugels (Kenney)
- 프로젝트 내 위치: `Unity/Client/Assets/ThirdParty/Kenney/RPGBase/`
- 사용 목적: 일반적인 마을 및 필드 환경 그래픽

## 라이선스

포함된 `license.txt` 기준 라이선스는 **CC0 (Creative Commons Zero 1.0)** 이다.

원문은 개인 및 상업 프로젝트에서 사용 가능하며, Kenney 또는 kenney.nl 표기는 선택 사항이고 의무가 아니라고 명시한다.

## 원본 보호

`Assets/ThirdParty/`의 PNG 원본은 수정하지 않는다. Unity Import Settings 변경은 가능하지만, 프로젝트 전용으로 편집한 에셋이 필요하면 `Assets/_Project/` 아래에 복사하여 사용한다.
