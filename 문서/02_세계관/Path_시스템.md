# Path 시스템

## 상태

🟢 5개 길 1차 프로토타입

## 정의와 역할

Path(길)는 한 사람이 삶을 경험해 온 방식이며 직업을 고정하지 않는다. 길은 **전투 행동을 바꾸는 고유 패시브**, 직업은 **능력치 + 전투 방식 + 액티브 스킬 + 직업 성장**을 담당한다. 5개 길과 5개 직업의 25개 조합을 모두 선택할 수 있다.

장애나 트라우마 자체가 초능력이나 육체적 힘을 만든다고 표현하지 않는다. 경험 이후의 감지, 협력, 도구 활용, 회복과 대응을 게임플레이 성향으로 다룬다.

## 공통 능력치

체력, 힘, 민첩, 감각, 지능, 의지의 기본값은 모두 10이다. 길은 이 기본 능력치에 직접 보너스를 주지 않는다.

## 현재 5개 길

| 길 | 고유 패시브 | 1차 효과 | 추천 시너지 |
|---|---|---|---|
| 시각의 길 | 집중 | 같은 실제 대상을 연속 단일 직접 공격하면 1~3중첩. 현재 중첩으로 해당 공격 피해 +3/+6/+9% | 투사·사수의 단일 공격 연계 |
| 청각의 길 | 잔향 포착 | 공격 행동을 마친 적에게 잔향. 해당 적에게 주는 다음 직접 피해 +10% 후 소비 | 사수·마도사의 대상 선택 |
| 지적의 길 | 패턴 익히기 | 같은 적이 같은 아군을 연속 직접 공격하면 다음 해당 피해 -10%, 패턴 보유 중 직접 치유 +10% | 수호자·치유사의 집중 공격 대응 |
| 지체의 길 | 굳건한 자리 | 전열 받는 직접 피해 -5%, 후열 주는 직접 피해·직접 치유 +5% | 수호자 전열, 마도사 후열 |
| 마음의 상처 | 회복탄력 | 자신 또는 생존 아군이 처음 HP 50% 이하가 되면 다음 2회 성공 행동의 직접 피해·치유 +10% | 투사의 반격, 치유사의 위기 회복 |

모든 길 상태는 `SelectedPlayerPathId`로 전투 시작 때 만들고 전투 종료 때 폐기한다. 태온·미엘에는 길을 부여하지 않으며 전투 중간 상태는 저장하지 않는다. 직접 피해·치유만 수치 보정을 받고 화상·독 같은 DoT에는 길 배율을 적용하지 않는다. 위 수치는 **1차 프로토타입 밸런스**다.
