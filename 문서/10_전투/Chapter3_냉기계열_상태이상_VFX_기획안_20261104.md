## 1. 목적 및 변경 불가 계약

Chapter3의 냉기 3종은 **각기 다른 상태이상**이다. 각 디버프를 보자마자 구분할 수 있는 전용 VFX를 제안하며, 텍스트·아이콘·턴/중첩 표시는 항상 함께 유지한다. VFX는 **기존 게임 규칙을 시각화하는 표현 계층**일 뿐 새로운 판정·피해·지속시간을 만들지 않는다.

- **한기:** 2턴 **모든 행동 불가**(공격·스킬·아이템·방어·화로 포함). 지속/재적용/행동 큐의 정확한 감소 규칙은 기존 기획의 TBD를 유지.
- **동상:** 별도로 부여되는 상태이며 **한기의 행동불가 효과 + HP 감소**. HP 감소량·틱 시점 TBD. 한기 누적으로 자동 진화하지 않는다.
- **동결괴사:** 보스 전용 **독립 1/3→2/3→3번째 적용 즉시 HP0·기존 전투불능**. 1·2중첩은 그 자체로 행동불가가 아니며, 영구사망·세이브 삭제도 아니다. 한기/동상으로부터 자동 진화하지 않는다.
- 상태 해제·화로 및 부활의 효과는 기존 공식 대응표 그대로 둔다. **정화Ⅱ**는 한기/동상·과열, **온기의 불꽃**과 **따끈 어묵탕**은 한기만, **해빙 연고**는 동상만, **보스 전투의 온기의 화로**는 생존 대상의 동결괴사 중첩만 제거한다. 화로는 회복·부활 수단이 아니다.
- 서리올빼미는 F2 첫 한기 전투의 연출 대상이지만, 한기 발동 주기·확률·정식 능력치·전리품·보상·냉기 상태 런타임은 별도 승인/TBD로 유지한다. QA 차용 Lv1/HP60/민첩10을 정식 값으로 승격하지 않는다.

## 2. 상태별 연출 제안

| 상태 | 부여 순간(원샷) | 유지(저강도 루프) | 효과 발생·해제 순간 | 반드시 병기할 UI |
|---|---|---|---|---|
| **한기** | 얇은 서리 고리, 짧은 찬 숨결, 작고 느린 눈 결정 | 캐릭터 외곽의 미약한 냉기·성에; 얼굴·손·무기·HP HUD 가림 최소화 | 행동불가를 알리는 짧은 고정 연출; 해제 때 성에가 바람에 흩어지며 사라짐 | **한기 / 행동불가 / 남은 턴** |
| **동상** | 몸 외곽에 서리 결정이 자라나는 느낌, 한기보다 무거운 실루엣 | 피부·장비 가장자리의 작은 갈라진 얼음 조각; 한기의 단순 안개와 다른 형태 | **실제 HP 감소 틱이 확정되어 발생할 때만** 짧은 결정 파열·HP 변화 피드백; 해제 시 결정 소실 | **동상 / 행동불가 + HP 감소 / 남은 턴 및 실제 HP 감소값** |
| **동결괴사** | 보스의 특수 냉기 흔적과 거친 결빙 문양 1회 | 1중첩: 작은 금, 2중첩: 뚜렷한 금과 위험 테두리(반짝임 없이), 단계마다 증가 | 3번째 적용 시 **KO 판정과 동기화된 1회 확정 연출**만; 화로 해제 때 검푸른 균열이 정리됨 | **동결괴사 1/3 또는 2/3**, 2/3에서 **다음 중첩 위험** 문자 경고, 3번째는 별도 **전투불능** |

**시각 차별화 기준**
- 한기는 **흐르는 안개·눈송이**, 동상은 **붙어 있는 얼음 결정·균열**, 동결괴사는 **금 간 어두운 결빙과 중첩 카운터**로 구분한다.
- 청색·회청색·검푸른색은 후보 팔레트일 뿐, **색만으로 게임 정보를 전달하지 않는다**. 상태명·아이콘 모양·수치가 우선이다.
- 상태가 중첩·동시 부여될 때, VFX의 명암과 알파를 무작정 합산하지 않는다. 여러 효과를 동시에 과하게 그려 실루엣이 사라지지 않도록 우선순위와 최대 화면 점유를 추후 Unity에서 검증한다. **효과의 동시 부여 가능 여부**는 기존 상태 로직에 따른다.
- 3/3은 지속 중첩 상태처럼 남겨 두지 않는다. 세 번째 적용은 즉시 기존 KO 처리로 연결하므로 연출 역시 **KO 순간**만 표기한다.

## 3. 공통 VFX 구조 (아트/기술 제작 전 계약 초안)

1. **상태 부여 이벤트** → 상태가 실제로 성공했을 때만 원샷. 저항·무효·회피·취소에 허위 냉기 부여 연출 금지.
2. **유지 표현** → 생존한 해당 대상의 실제 상태가 활성일 때만 반복; 턴/중첩이 소멸하면 곧바로 종료. 루프는 작고 느리게.
3. **틱·중첩 변경** → HP 감소/중첩 상승처럼 실제 전투 결과가 바뀔 때만 개별 피드백. 상태를 매 프레임 재적용하지 않는다.
4. **정화·아이템·화로 사용** → 기존 효과 표에 의해 **실제 해제가 성공한 종류만** 별도 소실 연출. 정화Ⅰ로 동상을 제거한 것처럼 표시하지 않는다.
5. **KO·전투 종료·Scene 전환** → VFX 인스턴스와 아이콘 잔존/미정리 방지. 세이브 데이터에 일회성 시각 효과를 쓰지 않는다.

**제작 권장 단위(미승인 기술안):** 가급적 하나의 공용 성에/냉기 기초 소재에 각 상태의 모양·강도·원샷/루프를 분리한다. 서로 다른 VFX임을 유지하면서도 새 파일을 무리하게 대량 양산하지 않는다. 아트 원화·SFX·애니메이션의 실제 종류, 파일명, PPU, FPS, 크기, 파티클 수, 지속 초, Sorting, 재생 속도, 색상 코드, SDK/플러그인은 **실물 QA 전에 TBD**이며 새로 고정하지 않는다. 기존 ThirdParty 효과의 상업적 재사용 권리는 사전 확인해야 한다.

## 4. 서리올빼미 및 보스 연출 연계

### 4-1. F2 서리올빼미 — 첫 한기 학습
- **날개 냉기 모으기**(예고): 공격 모션을 가리지 않는 작은 냉기 집중 연출. 공격 실루엣·기존 승인 Idle8/Attack4 프레임 자체 수정 금지.
- 실제 한기 부여 성공 시에만 대상에게 한기 원샷→유지 루프를 적용. 별도의 동상·동결괴사 연출을 F2 일반 서리올빼미에 끼워 넣지 않는다.
- 한기를 처음 경험하는 플레이어에게 텍스트+아이콘으로 ‘2턴 행동불가’와 가능한 해제 경로를 알리는 **안내 UI 방향**을 제안한다. 강제 조작·시간제한·무료 해제 획득/상점 가격·실제 시점은 기존 Main24의 미확정 계약으로 유지.
- F2 960/1280/1680×720에서 올빼미 안내 표식의 화면 경계 문제는 [Issue #87](https://github.com/HappyPaul812/Project-Limitless/issues/87) 별도 처리. 이번 VFX 문서가 UI 표식·Camera·HUD·승인 스프라이트를 변경하지 않는다.

### 4-2. 동결괴사 보스 — 위험과 해결 명확화
- 1/3은 결빙 균열 시작, 2/3은 아이콘 숫자 **2/3** 및 ‘다음 중첩 위험’ 안내를 더 분명히 한다.
- 3번째 부여의 실제 즉시 KO와 VFX를 일치시키되 빠른 점멸·화면 전체 백색 플래시·화면 흔들림을 필수 연출로 쓰지 않는다.
- **온기의 화로**는 해당 보스 Battle UI의 행동 1회 소비·대상 선택/취소 계약을 유지한다. 성공 시 해당 대상의 동결괴사 균열만 부드럽게 사라지는 시각 피드백을 제안한다. 화로가 한기·동상·HP·전투불능을 해제한 것처럼 연출하지 않는다.
- 2/3 경고를 표현하는 것으로 대응 기회를 보장했다고 판단하지 않는다. 3번째 전에 최소 한 번의 **실제 유효 대응 행동**을 보장해야 한다는 기존 공정성 원칙을 지킨다.

## 5. 접근성 및 HUD 안전 기준

- **색상 의존 금지:** 세 상태에 각각 모양이 다른 아이콘과 상태명, 남은 턴/중첩 또는 HP 감소 텍스트 병기. 무음 환경에서도 이해 가능.
- **과한 점멸·광량·움직임 금지:** 짧은 원샷과 약한 루프 우선, 화면 전체 백색 섬광/고주파 번쩍임/강한 카메라 흔들림·필수 빠른 반응 금지.
- **정보 가림 방지:** 아군/적 얼굴·무기·선택 외곽선, HP/MP, 턴 순서, 2행×3열 스킬 메뉴, 하단 HUD, 조작 버튼과 겹침 방지. 소형 40px 표시와 밝은 설원 배경에서도 대비 확인.
- **선택지와 입력:** 동일한 정보를 텍스트로 확인할 수 있어야 하며, 마우스·키보드·패드 사용을 제한하지 않는다. 효과 때문에 클릭 대상·포커스가 바뀌거나 입력 대기 시간이 짧아지지 않는다.
- **저동작 대안(제안):** 향후 VFX 강도 낮추기/루프 생략 등 접근성 설정이 가능하도록 원샷·유지 효과를 분리 설계한다. 실제 메뉴 옵션 도입은 이번 승인 대상이 아니다.
