# 스킬

## 목적

직업별 실제 전투 스킬의 데이터, 실행, 상태효과와 검증 상태를 관리한다.

## 상태

🟡 공용 구조 및 수호자 도발·치유사 치유의 빛·사수 정조준·화살비·동료의 습격·투사 난도·회심의 일격·회오리 베기 1차 구현

## 구현 구조

- `JobDefinition.StartingSkills`: 캐릭터 생성 프리뷰와 안정적인 Skill ID 제공
- `BattleSkillCatalog`: 프리뷰를 전투 메뉴용 정의로 변환하고 실제 구현 여부·효과·쿨타임·지속값 연결
- `BattleSkillExecutor`: 사용 가능 여부와 효과 실행 담당
- `BattleSkillCooldowns`: 참가자별·스킬별 쿨타임을 해당 참가자의 행동 차례 기준으로 관리
- `BattleStatusEffectRuntime`: 도발 적용과 전투불능 시 무효 상태 정리
- `BattleFighterResourceRuntime`: 참가자별 기세와 난도 스킬 직접 사용 횟수를 서로 분리해 관리
- `BattleSceneController`: 현재 행동자의 직업 스킬 메뉴, 입력, HUD 표시 연결
- `BattleActionPresenter`: 계산과 분리된 공용 스킬 강조 연출

## 현재 구현 스킬

### 수호자 도발 (`guardian_taunt`)

- 적 전체에 적용
- 적마다 다음 2회 실제 행동을 독립적으로 추적
- 단일 적대 행동의 대상을 수호자로 강제하며 일반 Target Range보다 우선
- 광역 공격과 비적대 행동에는 영향 없음
- 수호자 전투불능 시 해제
- 수호자 자신의 행동 기준 재사용 대기시간 3턴
- 적 HUD에 `도발 2`, `도발 1` 표시
- 3대3에서는 슬라임 세 개가 상태를 각각 보관하고 자기 행동 완료 때만 남은 횟수를 소모

### 치유사 치유의 빛 (`healer_healing_light`)

- 자신을 포함한 같은 진영의 살아 있는 아군 1명을 선택
- 적과 전투불능 아군은 선택 불가하며 부활 효과 없음
- 대상 최대 HP의 35%를 올림 정수로 회복하고 최대 HP를 초과하지 않음
- 최대 HP 대상은 선택할 수 있지만 안내 후 행동을 소비하지 않고 스킬 메뉴로 복귀
- 스킬 데이터의 `MaxHpHealRatio=0.35`를 사용하며 1차 구현에는 별도 쿨타임 없음
- PVFX Foundry 0.3.0 Radiant Heal grid 96×96 14프레임을 대상 위치에서 50ms 간격으로 재생
- manifest `peak`인 7프레임에서 실제 회복과 `+회복량`, HP HUD·상세 팝업 갱신 실행
- 대상 선택 중 Esc/취소는 스킬 메뉴, 스킬 메뉴 Esc/취소는 기본 명령으로 복귀

### 사수 정조준 (`sharpshooter_aim`)

- 강한 단일 원거리 물리 공격
- 기존 `TargetResolver`의 원거리 규칙을 사용해 후열 생존 시 후열만, 후열 전멸 후 전열만 선택
- 기본 공격력의 160%를 정수 퍼센트 올림으로 계산: `(Attack×160+99)/100`
- Projectile 도착 시 기존 `TakeDamage`를 호출하므로 방어 50%를 유지하고 방어 무시·치명타·상태이상 없음
- 사수 자신의 행동 기준 재사용 2턴: 사용 직후 2, 다음 사수 행동 1, 그다음 사용 가능
- `정조준!` 강조 뒤 기존 golden_arrow를 0.42초 동안 이동하고 도착 순간 피해·HP HUD·피격 연출 갱신
- 대상 선택 중 Esc/취소는 스킬 메뉴, 스킬 메뉴 Esc/취소는 기본 명령으로 복귀

### 사수 화살비 (`sharpshooter_arrow_rain`)

- 스킬 범위 `EnemyRearRowAll`로 살아 있는 적 후열 전체만 공격하며, 후열이 비어도 전열로 전환하지 않음
- 후열 대상이 0명이면 안내 후 Projectile과 행동을 시작하지 않고 스킬 메뉴 유지
- 각 후열 대상에 일반 공격의 120%를 정수 올림으로 계산하고 `TakeDamage`의 기존 방어 50% 유지
- Kenney `bow` 아이콘과 기존 Polar_34 `golden_arrow` 8프레임을 원본 수정 없이 재사용
- 짧은 조준→화살 3발 상승→0.16초 대기→대상마다 장식 화살 3발 낙하→공유 타격→동시 피격 순서로 약 0.75초 재생
- 장식 Projectile 수와 피해 횟수를 분리하여 대상마다 실제 120% 피해는 한 번만 적용
- 모든 피격 반응까지 끝나 사용 성공이 확정되면 사수 자신의 행동 기준 2턴 쿨타임 시작. 후열 0명 거절에는 쿨타임 없음
- 정조준과 화살비는 같은 `BattleSkillCooldowns`를 사용하지만 Skill ID별로 독립 저장되어 서로의 남은 턴을 변경하지 않음

### 사수 동료의 습격 (`sharpshooter_companion_attack`)

- 사수 전용 야수 동료 `BeastCompanion`이 등장해 지정 적을 공격하는 스킬이며 일반 파티 동료 `Companion`과 별도 시스템
- `BeastCompanion`은 별도 `Combatant`가 아니므로 HP, 독립 턴, Formation 슬롯이 없고 공격 대상이 되지 않음
- 살아 있는 적 1명을 전열/후열 구분 없이 선택하되 단일 적대 행동이므로 공용 `TargetResolver`의 도발 강제 대상을 우선
- 기본 공격의 180%를 정수 올림으로 계산하고 접촉 순간 `TakeDamage()`를 호출해 기존 방어 50% 감소 유지
- 사수 자신의 행동 기준 3턴 쿨타임이며 다른 스킬 쿨타임과 Skill ID별로 독립
- 1차 구현은 기본 Wolf가 사수 위치 근처에서 대상 바로 앞까지 Run 12 FPS와 Transform 이동을 함께 사용해 돌진하며, 최초 구현 이동 속도의 2/3을 사용
- 대상 바로 앞 도착 순간에만 피해를 적용하고 Wolf가 관통하지 않고 잠깐 멈춘 뒤 제거되며, 피격·제거 완료 뒤 다음 턴 진행
- `BeastCompanionCatalog`가 `BeastCompanionDefinition`을 제공하므로 `BattleSceneController`에는 Wolf 경로가 없고 향후 Bear/Fox 장착 데이터로 교체 가능
- 아이콘은 Wolf Run 원본 SpriteSheet에서 작은 버튼에서도 몸통·머리·꼬리·다리가 비교적 잘 구분되는 다섯 번째 프레임(index 4)을 런타임에 잘라 표시하며 원본 PNG는 수정하지 않음. 경로와 프레임 번호는 `BeastCompanionDefinition`이 제공하고 정조준은 기존 Kenney `target.png` 유지
- 야수별 기본 피해를 크게 차등화하지 않고 패시브 성향과 플레이 스타일을 선택의 중심으로 유지
- 야수 선택 UI, 장착·저장, Wolf 공격력 계열·Bear 방어/최대 HP 계열·Fox 민첩/행동 우선도/치명 계열의 실제 버프와 정확한 수치는 미구현

### 투사 난도 (`fighter_slash_stack`)

- `난도`는 스킬 이름이며, 공격 적중 후 얻는 투사 개인 전투 자원 이름은 `기세`
- 기존 근거리 `TargetResolver` 규칙으로 살아 있는 적 1명을 선택해 일반 공격 피해의 150%를 가함
- 기존 근거리 기본 공격 연출을 재사용하며 실제 타격 순간 피해를 적용한 뒤 자신에게 기세 +1
- 기세가 이미 3이면 `기세가 이미 최대입니다.` 안내 후 행동과 쿨타임을 소비하지 않음
- 난도 스킬의 성공한 직접 사용을 별도로 세며, 세 번째 직접 사용 때 투사 행동 기준 2턴 쿨타임 시작
- 기세가 3이라는 사실 자체는 쿨타임 조건이 아니며 회심의 일격으로 기세를 소비해도 난도 쿨타임은 유지
- 난도 버튼은 `cross`, 기세 상태는 `skull` 아이콘 사용

### 투사 회심의 일격 (`fighter_finishing_strike`)

- 기존 근거리 `TargetResolver`와 전진·타격·피격·복귀 Presenter를 재사용하는 단일 근거리 물리 공격
- 타격 순간 기세 0/1/2/3을 일반 공격의 100/130/160/190%로 변환해 정수 올림 피해 적용
- 피해가 정상 적용된 뒤 기세를 전부 소비하며 기세 0에서도 100% 피해로 사용 가능
- 자체 쿨타임은 없고 난도 스킬의 남은 쿨타임을 변경하지 않음
- 버튼은 `skull`, 상단 HUD는 기세 1~3에 `skull + 기세 n`, 상세 팝업은 `기세 0/3~3/3` 표시
- 스킬 설명 팝업은 데이터의 기세별 배율을 읽어 현재 기세와 현재 예상 피해 배율도 표시

### 투사 회오리 베기 (`fighter_whirlwind`)

- 스킬 전용 범위 데이터 `EnemyFrontRowAll`로 살아 있는 적 전열 전체만 대상으로 삼는 광역 근거리 물리 공격. 전열이 비어도 후열로 범위를 넓히지 않음
- 타격 순간 각 적에게 일반 공격의 80%를 정수 올림으로 계산하고, 각 대상의 기존 방어 50% 처리를 유지
- 실제로 맞힌 적 1명당 공용 `AddMomentum` API로 기세 +1, 최대 3
- 회오리 베기의 기세 획득은 난도 직접 사용 기록을 늘리지 않으므로 난도 쿨타임을 발생시키지 않음
- 자체 쿨타임과 대상 선택이 없으며 `spinner` 아이콘과 짧은 코드 기반 회전 참격 연출 사용

### 향후 직업별 광역 범위

- 투사 `회오리 베기`: `EnemyFrontRowAll` — 적 전열 전체만 공격(구현됨)
- 사수 `화살비`: `EnemyRearRowAll` — 적 후열 전체만 공격(구현됨)
- 마도사 `썬더볼트`: `EnemyAll` — 적 전열과 후열 전체 공격(범위만 확정, 미구현)
- 기본 공격의 근거리·원거리·마법 접근 규칙과 스킬 고유 광역 범위를 분리해, 전열 전멸 시 후열 노출 같은 기본 공격 규칙이 전열 전용 스킬에 섞이지 않게 함

## 다음 구현 후보

- 마도사: `파이어 볼`

구현되지 않은 스킬은 현재 전투 스킬 메뉴에 `[미구현]`으로 표시하고 실행하지 않는다.

전투 대상 선택 UI는 적·아군 후보 목록을 모두 받을 수 있게 분리되어 있다. 공격은 `TargetResolver`의 적대 사거리 후보를, 치유의 빛은 같은 Formation의 `LivingMembers`를 전달하므로 향후 단일 아군 버프에도 같은 입력 흐름을 확장할 수 있다.
