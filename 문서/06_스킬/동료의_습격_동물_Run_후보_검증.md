# 동료의 습격 동물 Run 후보 검증

## 목적과 구현 경계

사수의 세 번째 스킬 `동료의 습격`에 사용할 1차 기본 야수를 결정하기 위해 Wolf/Fox/Bear의 Run을 같은 조건에서 비교했다.
이번 작업은 Sprite 검증만 포함하며 피해, 대상 선택, 턴 진행, 기존 Battle Scene과 전투 계산에는 연결하지 않는다.

검증 결과 Wolf를 1차 기본 `BeastCompanion`으로 확정했다. Bear와 Fox도 향후 선택·장착 가능한 사수 전용 야수로 유지하며 삭제하지 않는다.

## 조사 방법

- PNG의 전체 크기와 알파 채널을 직접 읽었다.
- 모든 시트가 가로 64px 단위 프레임으로 정확히 나뉘는지 확인했다.
- 각 프레임의 불투명 픽셀 최소/최대 범위를 구해 실제 캐릭터 폭·높이와 바닥 여백 변화를 비교했다.
- PNG에는 Unity Pivot 정보가 들어 있지 않으므로 원본 Pivot이라고 단정하지 않는다. 검증 리소스는 모든 프레임을 아래 중앙 `(0.5, 0)`으로 명시적으로 통일한다.

공식 페이지는 각 동물에 Walk/Run/Idle이 있다고 설명하지만 실제 `All.zip`의 Wolf에는 Idle 대신 Howl만 있다. 이 차이는 원본 ZIP을 기준으로 기록하며 임의의 Idle 파일을 만들지 않는다.

### Wolf Run

- 프레임 실제 몸체 범위: 폭 52~54px, 높이 29~31px
- 바닥 여백: 0~1px
- 몸통 길이와 크기 변화가 작고 발과 꼬리 동작이 명확하다.
- 6프레임 순환이 부드럽고 자세가 낮아 빠르게 사냥감을 추격하는 인상이 강하다.

### Fox Run

- 프레임 실제 몸체 범위: 폭 56~57px, 높이 28~30px
- 바닥 여백: 0~1px
- 세 후보 중 프레임별 실루엣 크기가 가장 일정하다.
- 긴 꼬리와 낮은 자세로 속도감이 좋지만 몸통이 가늘어 같은 2배 표시에서 전투 캐릭터보다 가볍고 작게 느껴질 수 있다.

### Bear Run

- 프레임 실제 몸체 범위: 폭 53~60px, 높이 28~31px
- 바닥 여백: 보통 1px, 몸을 웅크린 공중 동작 프레임은 4px
- 폭 변화가 세 후보 중 가장 크고 5프레임이라 같은 FPS에서 순환이 가장 짧다.
- 큰 덩치의 충돌감은 강하지만 한 프레임의 도약이 눈에 띄며, 빠른 동료 돌진보다 무거운 돌격으로 보인다.

## Unity Import와 비교 조건

- Run 원본과 동일한 PNG를 `Assets/_Project/Resources/CompanionAssaultValidation/`에 복사했다.
- Point Filter, Mipmap 끔, 압축 없음, Alpha Transparency, 원본 크기 유지로 Import한다.
- 실행 중 가로 64px씩 프레임을 나누며 모든 Sprite Pivot을 아래 중앙으로 통일한다.
- 12 FPS는 한 프레임 약 0.083초다. FPS가 높으면 발동이 민첩해지고 낮으면 각 포즈와 무게감이 더 보이므로 `+/-`로 1~24 FPS를 비교할 수 있다.
- Sprite 프레임 재생과 UI Transform 이동을 분리하여 애니메이션 박자와 실제 돌진 시간을 독립적으로 판단한다.
- 세 원본은 왼쪽을 향하므로 기본 재생이 아군 오른쪽→적 왼쪽 연출에 맞는다. `F`는 X축 Scale을 반대로 하여 같은 프레임의 반대 방향 재사용을 검증한다.
- 2배 표시는 64px 프레임을 최대 128px 폭으로 보여 주며 현재 Battle의 아군 Sprite 표시 영역 112px, 적 136px 사이와 비교하기 쉽다.

## 후보 평가

### Wolf

- 장점: 동료·사냥·명령 수행의 의미가 가장 즉시 전달되고, 낮은 자세와 6프레임 보폭이 빠른 추격에 잘 맞는다. 현재 Battle 표시 크기에서도 너무 작거나 크지 않다.
- 단점: 실제 ZIP에 독립 Idle이 없어 향후 명령 대기나 복귀 연출에 Idle이 필요하면 Howl 또는 별도 처리 검토가 필요하다.
- Run 적합성: 매우 높음. 기본 왼쪽 방향을 그대로 사용하며 오른쪽→왼쪽 돌진이 자연스럽고 Flip도 실루엣상 무리가 없다.

### Fox

- 장점: 실루엣 변화가 가장 안정적이고 6프레임 달리기가 부드럽다. 빠르고 영리한 사수 동료의 인상을 줄 수 있다.
- 단점: 가는 다리와 몸통 때문에 2배에서도 Wolf/Bear보다 공격 충돌의 무게가 약하고, 전투 화면에서 작은 동물처럼 느껴질 수 있다.
- Run 적합성: 높음. 속도감과 좌우 Flip은 좋지만 강한 타격보다는 재빠른 통과 공격에 어울린다.

### Bear

- 장점: 덩치와 앞발 움직임이 충돌 순간의 힘을 가장 강하게 전달하고 전투 화면에서 존재감이 크다.
- 단점: 5프레임과 큰 폭 변화로 같은 FPS에서 다소 거칠며, 묵직한 야생 동물 돌격이 사수의 상시 동료보다 소환수·필살기처럼 보일 수 있다.
- Run 적합성: 보통 이상. 공격성은 좋지만 빠르게 달려 화면을 통과하는 기본 연출에서는 Wolf/Fox보다 둔중하다.

## 추천

1차 기본 야수는 **Wolf**다. 동료라는 의미, 사냥감 추격 자세, 공격 돌진의 가독성, 현재 전투 Sprite 표시 영역과의 균형이 가장 좋다.
Fox와 Bear도 탈락 자산이 아니라 향후 선택 가능한 `BeastCompanion`으로 유지한다. 1차 `동료의 습격`은 Wolf를 사용하되 `BattleSceneController`에 직접 고정하지 않고 이후 장착 야수 데이터로 교체할 수 있는 구조를 전제로 한다.

Boar도 돌진 공격 자체에는 어울리지만 `동료`라는 인상과 사수의 사냥 파트너 가독성이 Wolf보다 뚜렷하게 우수하지 않아 이번 비교 Scene에는 추가하지 않았다.

## 사용자 검증 절차

1. Unity에서 `Assets/_Project/Scenes/Validation/CompanionAssaultRunValidation.unity`를 연다.
2. Play를 눌러 세 후보의 오른쪽→왼쪽 달리기를 같은 조건으로 본다.
3. `Space`로 한 프레임 실루엣과 발 기준선을 멈춰 비교한다.
4. `+/-`로 FPS를 바꾸어 속도감과 무게감을 비교한다.
5. `F`로 왼쪽→오른쪽 Flip 재생이 자연스러운지 확인한다.

검증 Scene은 Build Settings에 넣지 않았으며 실제 Battle Scene과 전투 시스템에는 영향을 주지 않는다.
