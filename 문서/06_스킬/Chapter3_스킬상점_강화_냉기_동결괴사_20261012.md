- **가격 원칙(확정):** 강화판과 신규 스킬 모두 '저렴한 실전 수단'으로 취급한다. 처음 상점에 도달한 플레이어가 정상적으로 퀘스트·전투·잡템 판매를 수행하며 순차적으로 구매할 수 있도록 하고, 새로운 필수 대응 스킬 획득이 반복 노가다를 요구하지 않게 한다.
- **우선순위:** 스킬을 충분히 마련한 뒤 펫·소모품 등 다양한 선택을 즐기는 구조. 기존 펫 분양 100탈렌트와 냉기 해제약·회복약에 필요한 여유를 고려하며, 스킬을 고가 '사치품'으로 설정하지 않는다.

- **가격 숫자 아직 미확정:** 강화판/신규/상위 스킬 사이의 개별 값과 해금·할인 여부는 Chapter2 완료 시 실측 잔고, Chapter3 예상 수입(전투·퀘스트·잡템)을 보며 별도 결정한다. 현재 미승인 제안 가격이나 펫 가격을 임의로 수정하지 않는다.
- **검증 방향:** 진행 구간별 평균/최소 탈렌트 잔고, 스킬 구매 뒤 기본 포션·대응약 구매 가능 여부, 펫 분양과 충돌 정도를 점검. 신규 스킬 입고가 캐릭터 전력 상승에 앞서 과도한 재화 파밍을 요구하면 가격을 낮춘다.

- 스킬 습득은 전용 스킬 상점/NPC에서 탈렌트로 거래하되, 기존 일반 아이템 상점과 구현을 구분한다. '신규 NPC를 반드시 만든다'는 결정은 없다.
- **사용자 확정:** 장착/해제는 게임 메뉴의 `스킬 관리`에서 **전투 밖 어디서든 무료로** 허용한다. 안전지역·파티 안내인 복귀는 필수 조건이 아니다. 별도의 스킬 장착 전용 NPC가 필수인 운영도 채택하지 않는다.
- 전투, 전투 진입/결과 전환, 컷신·대화·강제 이벤트 등 조작 불가 상태에서는 장착 변경을 잠근다. **전투 시작 때 장착 세트를 확정**, 전투 중 장착 교체로 쿨다운·행동·보스 규칙을 우회하는 일을 막는다.
- 안전지역의 파티 안내인은 **동료 편성/진형 관리** 용도로 유지하고, 그곳 메뉴에 `스킬 관리` 바로가기를 붙일 수 있다. 현장 장착을 위해 거점 복귀하거나 새 전용 NPC에게 말을 거는 강제 절차는 추가하지 않는다(제안).
- **확정:** 시작은 직업마다 3개, Chapter3 신규 목표는 2개(사수 예외)이며 이후 챕터에서 수십 개로 누적될 수 있다. **동시에 장착 가능한 액티브 스킬은 최대 6개**이고 전투 메뉴에는 장착한 것만 표시한다. 강화판은 기존 슬롯을 승계하고 별도 칸을 차지하지 않는다. **2행×3열 스킬 선택**의 실제 위치·크기는 전장/HUD·상세 팝업과의 충돌을 검증해 구현 단계에서 조정한다.
- Save/Continue에서 `습득 여부`·`강화 단계`·`장착 슬롯/순서`를 안정된 Skill ID로 복원한다. 기존 15개 스킬과 저장 슬롯, 동료/펫/파티 편성을 보존한다. 슬롯 내 중복·미습득/타 직업 스킬·오래된 데이터의 안전 복구는 추후 기술 계약.
- 사용하기 쉬운 UI: 스킬명·효과·현재/강화 단계·장착 여부를 **텍스트+아이콘**으로 명시, 게임패드/키보드·마우스 버튼 대응, 드래그 강제 금지, 원클릭 슬롯 선택/교체+명시적 취소와 입력 복귀.

### 스킬 보관함 UI 확장 — 미장착 스킬이 많아질 경우

**장착 한도 6칸은 확정, 보관함 세부 UI는 기획 제안 / 바울 대표 시각·조작 승인 전**: 장착 슬롯(고정 상단 최대6)과 **전체 습득 스킬 보관함**(별도 스크롤·검색·분류)을 분리한다. 수십 종의 미장착 스킬을 전투 바닥이나 슬롯 아래 텍스트 한 줄로 늘어놓지 않는다.

- **장착 패널:** 왼쪽 또는 상단에 슬롯1~6을 고정, 스킬 아이콘·이름·종류·장착 위치·교체 및 해제 버튼. 강화판은 같은 원슬롯 표시만 업데이트. 빈 슬롯 허용.
- **보관함 패널:** 별도 영역에서 전체/장착 중/미장착/신규·강화 등 필터, 공격·방어·회복·보조 기능 분류, 이름 검색·정렬·스크롤 또는 페이지(성장 시 수량과 무관하게 같은 UI 유지).
- 스킬을 선택하면 **설명 패널**에 효과·자원·쿨타임·배운 경로·강화 단계·장착 여부를 표시하고 `장착 → 슬롯 선택`, `교체`, `해제`를 명시한다. 미습득 스킬을 보관함에 노출한다면 해금조건만 보여주고 장착 불가로 구분.
- 입력 접근성: 키보드/게임패드/마우스로 동일한 조작, 드래그 필수 동작 없음, 선택 및 취소 명확, 색 외에 텍스트·아이콘으로 상태 구분. 메뉴 포커스가 보관함과 장착 패널 사이에서 사라지지 않게 한다.
- 전투 중에는 **장착한 최대6개의 활성 스킬만** 제공한다. 보관함/습득 목록이 전투 메뉴에 표시되거나 장착 변경을 허용하지 않는다. 예비 슬롯·스킬 재정렬을 보스전 중 무제한 전략 교체로 취급하지 않는다.
- 장착을 바꿨다가 다시 장착해도 전투를 떠난 상태에서 기존 전투 중 쿨타임을 초기화하는 식의 우회는 허용하지 않는다. 전투 스냅샷은 전투 시작 시 확정.
- 펫 자체의 별도 패시브는 전투 스킬 슬롯을 차지하지 않는다(기존 펫 시스템 유지). 새 펫 명령이 실제 액티브 스킬로 설계된다면 슬롯 소모 여부를 별도 확정한다.

**상태:** 바울 대표 확정 = 강화 자동교체, 신규 자유 장착·해제, 전투 외 어디서나 변경 가능, **최대6개**, 전투 스킬 메뉴 **2행×3열**. 보관함 검색·분류·스크롤의 세부 레이아웃, 학습 NPC/판매 NPC의 신설 여부와 가격은 별도 미정. **구현 승인 없음**.
