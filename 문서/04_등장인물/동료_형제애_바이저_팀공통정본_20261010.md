# 동료·형제애·바이저 팀 공통 정본

2026-10-10 사용자 확정. **기획 정본 / 이번 서사 보완은 미구현 / 문서화 전용**. 기획·Codex·아트·TTS·BGM·개발기록 영상 담당이 함께 참조한다. 기존 Character 설정과 구현된 기능을 유지하며, 아래 미래 방향을 구현 완료로 해석하지 않는다.

## 인물과 일행·전투의 구분

플레이어는 별도 캐릭터이며 길과 직업을 직접 선택한다. 폴은 **사용자를 반영한 고유 동료**이고 플레이어가 아니다. 폴·미엘의 Slow Burn은 NPC 두 사람의 관계이며 플레이어·미엘의 관계가 아니다.

| 인물 | 확정한 길 | 직업 | 기존 구현 ID / 상태 |
| --- | --- | --- | --- |
| 플레이어 | 직접 선택 | 직접 선택 | 동료와 별도 캐릭터 |
| 폴 | 지체의 길 | 마도사 | `companion_paul` / `path.mobility` / `mage` |
| 미엘 | 마음의 상처의 길 | 치유사 | `companion_miel` / `path.emotional-scar` / `healer` |
| 태온 | 지적의 길 | 수호자 | `companion_taeon` / `path.intellectual` / `guardian` |
| 세린 | 청각의 길 | 사수 | `companion_serin` / `path.hearing` / `sharpshooter` |
| 태온 친형 | 시각의 길 | 투사 | Character ID·정확한 합류 시점/조건 미정, 미구현 |

Main21 시점 주요 일행은 **플레이어 + 기존 동료 4명 = 총 5명**이다. 형의 등장을 즉시 영구 합류로 해석하지 않는다. 전투는 **플레이어 1명 + 동료 2명 = 3인 편성**을 유지한다. 스토리 일행 5명은 항상 화면에서 따라다니는 Follow AI를 뜻하지 않는다. 전투 대기 동료도 스토리에서 사라지지 않으며 미편성 장면 처리는 [Path 반응형 Story 정본](../03_스토리/Path_반응형_Story_연출_규칙.md)을 따른다.

## 장애·성격·자기결정권

장애 유형으로 성격을 일반화하지 않는다. 청각장애인=소심함, 시각장애인=초인적 감각, 지적장애인=어린아이 같음 등의 고정관념을 사용하지 않는다. 장애 자체를 초능력·천재성·동정·극복 미담의 원인으로 만들지 않는다. 각 인물의 경험·성격·관계·도구 활용을 구분하고 모든 동료의 자기결정권을 존중한다. 길과 직업은 독립적이며 추천은 선택 제한이 아니다.

### 세린

세린은 침착하고 자기 의견이 분명하며 친밀한 관계에서 장난기를 보일 수 있는 독립적인 인물이다. 청각 보조 장치는 신호를 제공하고 의미를 판단하는 것은 세린 자신의 경험과 관찰이다. 기존 [세린 정본](세린.md)의 성격·공식 외형·합류 설정을 유지한다.

Main21에서 세린이 주도하는 정찰·잔존 위험 조사 등의 **실제 게임플레이를 검토**한다. Chapter3에서도 탐험과 판단에 기여한다. 폴·미엘 연애나 태온 형제 이야기를 구경하기만 하는 역할로 만들지 않으며 Chapter4/5까지 이야기에서 퇴장시키지 않는다. 별도 개인 서사의 정확한 시기와 Quest·Objective는 미정이다. 장치 신호가 자동으로 정답을 주거나 세린이 없으면 진행할 수 없는 조건으로 확대하지 않는다.

### 태온

지적의 길 + 수호자 정본과 **패턴 익히기**의 현재 이름·전투 효과를 유지한다. 반복 경험과 익숙해진 상황을 바탕으로 스스로 판단한다. 천재 분석가나 무능한 보호 대상, 어린아이로 묘사하지 않는다. 지적의 길을 대표할 신규 동료를 별도로 추가하지 않는다. 세부 표현과 전투 규칙은 [Path 시스템](../02_세계관/Path_시스템.md), 기존 성격은 [메인 스토리 정본](../03_스토리/메인_스토리와_퀘스트_설계.md#태온-1)을 따른다.

## 태온 친형과 마력 바이저

형은 **시각의 길 + 투사**다. 과거 태온을 지키다 눈을 다쳤으나 **눈 부상이 시각의 길을 자동 결정한 것은 아니다.** 부상과 성격·전투 능력을 인과적으로 단순화하지 않는다.

바이저는 사용자가 제시한 현실의 외부 카메라 기반 시각 보조·뇌 인터페이스 연구에서 **영감을 얻은 판타지 마도구 콘셉트**다. 현실 장치의 효과나 의료·과학적 구조를 설명하는 설정은 아니다.

- 가로형 마력 렌즈/바이저를 콘셉트로 한다.
- 마력과 문양을 통해 주변 형상·움직임의 **제한적 인식**을 보조한다.
- 완전한 시력 회복이나 만능 탐지 장치로 표현하지 않는다.
- 실제 뇌 이식·침·전극·과학적 구조 설명을 하지 않는다.
- 모든 시각의 길 캐릭터에게 동일 장치 착용을 강제하지 않는다. 기존 플레이어 바이저 Sprite나 외형 계약을 이번 문서화로 변경하지 않는다.
- 형의 현재 시력·바이저 세부 작동 방식·완성 외형은 미정이다. 콘셉트가 확정됐다는 이유로 임의의 최종 아트나 Character Asset을 만들지 않는다.

## 형제애와 마지막 칭찬

형제는 서로 가족식 반말을 쓴다. 형은 태온을 진심으로 아끼며 잘하면 속으로 뿌듯하지만 겉으로 쉽게 칭찬하지 않는다. 형의 보호 책임감과 태온의 자기결정권 사이에 갈등이 있다. 초반에는 여전히 부족하다고 생각하며 챙기려 하고, 중반에는 성장을 알면서도 쉽게 인정하거나 표현하지 못하며, 후반에는 태온의 판단을 믿고 맡기기 시작한다.

마지막 주요 전투·게임플레이 이후 형이 처음으로 직접 말한다.

> 잘.했.어.

**`잘.했.어.`의 글자·마침표·의미를 보존한다.** 태온이 칭찬을 얻으려고 성장하는 이야기가 아니라 형이 이미 성장해 온 태온을 인정하는 이야기다. 형의 승인을 자기결정권의 조건으로 만들지 않는다.

형제 1:1 대련안은 **폐기**됐다. 형제 협동 전투는 기존 3인 전투 규칙 안에서 검토하는 **미확정 후보**다. 정확한 편성·협동 스킬·전투 조건을 확정하지 않는다. 결말의 BGM 낮춤·짧은 여백·무뚝뚝한 말투·짧고 진심 어린 TTS·과도한 눈물/포옹 지양·명료한 자막과 충분한 읽기 시간은 [형제애 서사 정본](../03_스토리/Chapter3_태온_형제애_서사_20261010.md)을 따른다. Dialogue ID와 음성 제작은 후속 확정이다.

## Main21과 Chapter3 경계

**Main21은 Chapter2 마지막, Chapter3는 Main22부터**다. Main21은 서부 안정화 조사 → 초보 마을 귀환 → 폴·미엘의 짧은 Slow Burn → 태온 형 등장 → 북쪽 징후로 연결한다. 공식 고백·연애 확정은 하지 않는다.

대화가 연속하는 드라마형 Quest보다 플레이어가 직접 탐험·조사·전투하는 구성을 우선한다. Main21 상세 Objective, 잔존 몬스터·지맥 퍼즐·협동 전투는 후속 확정이다. 기존 [Chapter2 방향](../03_스토리/Chapter2_서부_방향.md)과 [Chapter3 환경 방향](../03_스토리/Chapter3_초기_방향.md)을 유지한다.
