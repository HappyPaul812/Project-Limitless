# 캐릭터 최종 확인

`FinalConfirmation`은 캐릭터 생성 4단계다. `GameSessionData`의 이름, 외형, 길 ID, 직업 ID를 읽고 각 ID에 해당하는 `PathDefinition`과 `JobDefinition`의 표시 데이터를 조합한다.

화면에는 캐릭터 미리보기와 이름·성별, 선택한 길과 전투 특성, 선택한 직업의 역할·능력치 보너스·패시브·시작 스킬 3개, 그리고 기본 10 + 직업 보너스로 계산한 6종 최종 능력치를 표시한다. 추천 여부는 현재 길의 `RecommendedJobs` ID로 판단하며 작은 `추천 조합` 안내에만 사용하고 선택 제한으로 사용하지 않는다.

중앙 패널은 `선택한 길 → 전투 특성 → 선택한 직업 → 시작 스킬` 순서로 읽힌다. 길 이름 옆에는 길 자체의 공식 `PathSymbol`을 64px로 크게 표시하고, 특성 이름 옆에는 기능을 나타내는 `TraitIcon`을 26px로 작게 표시한다. 두 이미지는 모두 원본 비율을 유지한다. 길 이름·특성 이름·설명과 두 Sprite는 `PathPresentationResolver`가 찾은 같은 `PlayerPathDefinition`에서 읽으며 FinalConfirmation 전용 문자열이나 Path별 분기문을 만들지 않는다. 특성 설명은 PathSelection 상세 패널과 동일한 `PassiveDescription`을 재사용한다.

오른쪽 능력치는 이름과 숫자를 각각 고정된 열에 배치해 2열 3행의 간격을 일정하게 유지한다. `기본 10 + 직업` 문구를 유지하며 길은 기본 능력치를 직접 올리지 않는다. 하단의 게임 시작 버튼은 이전 버튼보다 크기·배경·테두리를 강조한 Primary Action이지만 기존 Tab/Shift+Tab·방향키·Enter·Space 입력과 초기 Focus 정책은 그대로 유지한다.

기준 해상도는 1280×720이다. 중앙 패널의 특성 설명은 지정 영역에서 줄바꿈하고 넘치는 내용은 잘라 하단 직업 영역을 침범하지 않게 하며, 시작 스킬은 별도 열에 표시한다. 실제 폰트 렌더링과 다섯 길·다섯 직업의 모든 조합은 Play Mode에서 최종 확인한다.

이전 버튼은 `JobSelection`, 게임 시작 버튼은 `World_StarterVillage`로 이동한다. Scene 전환 중 선택값은 유지되지만 `GameSessionData`는 현재 실행을 위한 런타임 세션이므로 영구 저장 데이터가 아니다.

키보드에서는 Tab/Shift+Tab과 방향키로 버튼 사이를 이동하고 Enter 또는 Space로 실행한다. 초기 Focus는 게임 시작 버튼에 둔다.
