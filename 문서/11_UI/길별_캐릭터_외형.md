# 길별 캐릭터 외형

## 원칙

Path Visual은 길의 시각적 정체성이고 능력치 및 직업 전투 로직과 독립적이다. 모든 길과 모든 직업의 5×5 조합을 허용하며, 추천 직업은 선택 제한이 아니다. 외형 장치와 상징은 페널티가 아니라 정체성과 능력을 표현한다.

## 시각 정체성

- 청각의 길: 헤드폰을 포함한 Male/Female 전체 캐릭터 시트 (`CharacterVariant`)
- 시각의 길: 바이저를 포함한 Male/Female 전체 캐릭터 시트 (`CharacterVariant`)
- 지체의 길: 전투형 전동 휠체어 Male/Female 전체 캐릭터 시트 (`WheelchairVariant`)
- 지적의 길: 연결된 두 고리와 중앙 빛으로 구성된 동행의 문장 (`BodyEmblem`)
- 마음의 상처: 균열을 금빛 에너지가 잇는 심장석 (`BodyEmblem`)

## 데이터와 표시

`PlayerPathVisualDefinition`은 Path ID, Visual Mode, Male/Female 전용 Animator Controller와 Down Idle Sprite 등 캐릭터 외형 자료를 보관한다. 공식 UI 문장 `PathSymbol`과 전투 `TraitIcon`은 `PlayerPathDefinition`에서 PathId로 찾는다. 청각·시각·지체는 기존 `PlayerSpriteAnimator`가 사용하는 동일한 상태명과 방향 규칙의 전용 Animator로 전체 Visual을 교체하지만, 이 캐릭터 Sprite를 공식 PathSymbol로 사용하지 않는다.

PathSelection, JobSelection, FinalConfirmation은 Variant의 Down Idle Sprite를 미리보기 본체로 사용하고 별도의 공식 PathSymbol을 길 이름과 함께 표시한다. 지적·마음의 상처는 기본 캐릭터를 유지하며 World Body Overlay는 만들지 않는다. 모든 Variant 슬롯은 Animator와 Sprite가 모두 있을 때만 적용되므로 하나라도 비어 있으면 기존 캐릭터를 유지한다.
