# 길별 캐릭터 외형

## 원칙

Path Visual은 길의 시각적 정체성이고 능력치 및 직업 전투 로직과 독립적이다. 모든 길과 모든 직업의 5×5 조합을 허용하며, 추천 직업은 선택 제한이 아니다. 외형 장치와 상징은 페널티가 아니라 정체성과 능력을 표현한다.

## 시각 정체성

- 청각의 길: 파란색·금색 마도공학 헤드폰 (`HeadAccessory`)
- 시각의 길: 눈 영역의 금색·청색 마도공학 바이저 (`EyeAccessory`)
- 지체의 길: 이동 수단이자 강력한 장비인 전투형 전동 휠체어 (`Wheelchair`)
- 지적의 길: 연결된 두 고리와 중앙 빛으로 구성된 동행의 문장 (`BodyEmblem`)
- 마음의 상처: 균열을 금빛 에너지가 잇는 심장석 (`BodyEmblem`)

## 데이터와 표시

`PlayerPathVisualDefinition`은 Path ID, Visual Mode, Male/Female 4방향 Sprite, UI Symbol을 보관한다. 에셋은 `Assets/_Project/Resources/PathVisualDefinitions`에서 ID로 검색한다. 월드의 `PlayerPathVisualController`는 `PlayerSpriteAnimator.CurrentFacingDirection`을 재사용해 방향을 동기화한다. 일반 길은 Body 위 Overlay로 표시하고, 휠체어용 합성 Sprite가 준비된 경우에만 기본 Body를 숨긴다.

PathSelection, JobSelection, FinalConfirmation은 Down 방향 외형과 Symbol을 미리보기 위에 합성한다. Sprite 슬롯이 비어 있으면 기존 캐릭터를 유지한다.

## 필요한 아트

권장 루트는 `Assets/_Project/Art/Characters/PathVisuals/`이다. Hearing, Vision, Physical은 Male/Female 각각 Down·Left·Right·Up Sprite가 필요하다. Intellectual과 EmotionalScar는 방향별 Body Emblem과 별도 UI Symbol이 필요하다. 휠체어 이동 애니메이션은 실제로 서로 다른 프레임이 준비된 후 전용 Animator로 확장한다.
