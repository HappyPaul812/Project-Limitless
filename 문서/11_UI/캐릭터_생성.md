# Character Creation 최소 외형 선택

## 목적

새 게임 시작 시 플레이어가 Male 또는 Female 외형과 캐릭터 이름을 정하고, 선택한 정보로 Starter Village에 입장하게 한다.

1단계는 외형과 이름, 2단계는 길, 3단계 JobSelection은 전투 직업, 4단계 FinalConfirmation은 최종 결과 확인을 다룬다. 장비는 아직 포함하지 않으며 로컬 저장은 단일 슬롯을 사용한다.

## Scene 흐름

1. `Bootstrap` Scene은 유효한 저장이 있으면 `이어하기 / 새 게임`, 없으면 `새 게임`을 표시한다.
2. Character Creation 화면은 기본값으로 Male을 선택한다.
3. 플레이어가 Male 또는 Female 버튼을 선택하고 캐릭터 이름을 입력한다.
4. 유효한 이름으로 `다음` 버튼을 누르면 선택값을 유지한 채 `PathSelection` Scene을 불러온다.
5. PathSelection에서 실제 5개 길 중 하나를 선택하고 이후 단계로 진행한다.
6. JobSelection에서 5개 기본 직업 중 하나를 선택한다.
7. FinalConfirmation에서 이름, 외형, 길, 직업, 시작 스킬과 최종 능력치를 확인한 뒤 월드로 이동한다.

## 선택값 유지

`GameSessionData`는 현재 실행 중인 게임 세션의 선택과 진행값을 보관한다. `GameSaveData`는 이 값 중 영구 보존할 ID와 숫자를 JSON 파일에 따로 기록한다.

Bootstrap에서 새 게임을 선택하면 기본 Male, 빈 이름, Path 미선택으로 초기화된다. PathSelection의 `이전`으로 돌아오면 Bootstrap을 거치지 않으므로 기존 Male/Female과 이름을 UI에 복원한다. FinalConfirmation 확정 시 이름·외형·길·직업과 기본 레벨 1·경험치 0을 첫 저장한다.

## UI 구성

- 금색 `PROJECT LIMITLESS` 제목과 `캐릭터 생성` 섹션 제목
- 외부 이미지 없이 여러 uGUI Image를 겹친 짙은 네이비 배경, 중앙 패널, 약한 가장자리 비네트
- 실제 Male Down Idle Sprite가 포함된 남성 선택 카드
- 실제 Female Down Idle Sprite가 포함된 여성 선택 카드
- `현재 선택: 남성/여성` 상태 문구
- 별도 패널에 배치된 `캐릭터 이름` 라벨과 `이름을 입력하세요` 입력란
- 이름이 잘못되었을 때 입력란 가까이에 표시되는 오류 문구
- 금색 테두리를 가진 주요 `다음` 버튼
- 키보드 조작 안내
- `1 기본 정보 / 2 길 / 3 직업 / 4 확인` 단계 표시

선택 카드는 어두운 반투명 패널, 캐릭터 미리보기 프레임, 구분선으로 구성한다. 선택 상태는 밝아진 배경과 금색 굵은 테두리, `✓ 선택됨` 텍스트를 함께 사용한다. 키보드 Focus는 더 밝은 금색 테두리로 표시하므로 색상만으로 선택과 Focus를 구분하지 않는다.

Canvas는 기존과 같이 `Screen Space - Overlay`를 사용한다. Overlay UI만 있는 Scene도 화면은 표시되지만 Camera가 없으면 Unity Game View가 `Display 1 / No cameras rendering` 안내를 겹쳐 표시한다. 따라서 CharacterCreation Scene에는 UI 배치와 입력에 영향을 주지 않는 최소 Orthographic Camera를 함께 둔다.

## 접근성

- 외형을 그림이나 색상만으로 구분하지 않고 남성/여성 텍스트를 함께 표시한다.
- 선택된 항목에 `✓ 선택됨` 문구, 상태 문구, 굵은 테두리를 함께 표시한다.
- 버튼을 크게 배치한다.
- 마우스 클릭을 지원한다.
- 방향키와 Tab/Shift+Tab으로 이동할 수 있다.
- Enter 또는 Space로 선택하거나 게임을 시작할 수 있다.
- 이름 입력 중에는 문자와 방향키가 외형 선택 단축키로 처리되지 않는다.
- 입력란에서 유효한 이름으로 Enter를 누르면 게임을 시작할 수 있다.
- 선택 카드, 이름 입력란, 게임 시작 버튼은 Focus 시 4px 금색 테두리를 표시한다.
- 선택 시간 제한이 없다.

## 이름 규칙

- 앞뒤 공백은 제거한다.
- 한 글자 이상 12자 이하로 제한한다.
- 한글 완성형, 영문 대·소문자, 숫자를 허용한다.
- 공백만 있는 이름과 특수문자는 허용하지 않는다.
- 잘못된 이름이면 Scene을 이동하지 않고 이해하기 쉬운 오류 문구를 표시한다.

프로젝트에 한글용 TMP Font Asset이 아직 없으므로 이름 입력란은 기존 UI와 같은 `LegacyRuntime.ttf` 기반 uGUI `InputField`를 사용한다. 이를 통해 기존 한글 표시 방식과 IME 입력 경로를 유지한다.

## Editor 생성 메뉴

`Project-Limitless/Milestone 01/Generate Character Creation Scene`은 다음 항목만 갱신한다.

- `CharacterCreation.unity`
- `PathSelection.unity`
- `JobSelection.unity`
- `FinalConfirmation.unity`
- CharacterCreation용 최소 Camera
- PathSelection과 JobSelection용 최소 Camera
- Bootstrap의 시작 Scene 설정
- Build Settings의 Scene 순서

기존 `World_StarterVillage` Scene은 재생성하지 않는다. Build Settings 순서는 Bootstrap, CharacterCreation, PathSelection, JobSelection, FinalConfirmation, World_StarterVillage이다. 이 흐름의 `GameSessionData`는 실행 중 Scene 사이에서 값을 유지하는 런타임 세션이며 영구 저장 파일은 아니다.

화면 디자인은 `CharacterCreationController`가 런타임에 생성하므로 전용 생성 메뉴로 Scene을 다시 만들어도 동일한 디자인이 유지된다.
