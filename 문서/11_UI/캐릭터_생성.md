# Character Creation 최소 외형 선택

## 목적

새 게임 시작 시 플레이어가 Male 또는 Female 외형을 선택하고, 선택한 모습으로 Starter Village에 입장하게 한다.

이번 단계는 외형 선택만 다룬다. 이름, 직업, Path, 능력치, 장비, 저장 슬롯은 포함하지 않는다.

## Scene 흐름

1. `Bootstrap` Scene이 `CharacterCreation` Scene을 불러온다.
2. Character Creation 화면은 기본값으로 Male을 선택한다.
3. 플레이어가 Male 또는 Female 버튼을 선택한다.
4. 게임 시작 버튼을 누르면 선택값을 유지한 채 `World_StarterVillage` Scene을 불러온다.
5. 월드의 `PlayerVisualController`가 선택값을 읽어 해당 Sprite와 Animator를 적용한다.

## 선택값 유지

`GameSessionData`는 현재 실행 중인 게임 세션의 `PlayerVisualType`을 static 값으로 보관한다. static 값은 Scene이 바뀌어도 유지되므로 별도의 저장 파일 없이 Character Creation에서 Starter Village로 선택을 전달할 수 있다.

게임을 다시 실행하면 기본 Male로 초기화된다. 영구 저장과 불러오기는 이후 저장 시스템에서 구현한다.

## UI 구성

- Project-Limitless 제목
- 캐릭터 선택 안내
- 실제 Male Down Idle Sprite가 포함된 남성 선택 버튼
- 실제 Female Down Idle Sprite가 포함된 여성 선택 버튼
- `현재 선택: 남성/여성` 상태 문구
- 게임 시작 버튼
- 키보드 조작 안내

## 접근성

- 외형을 그림이나 색상만으로 구분하지 않고 남성/여성 텍스트를 함께 표시한다.
- 선택된 항목에 `✓ 선택됨` 문구, 상태 문구, 굵은 테두리를 함께 표시한다.
- 버튼을 크게 배치한다.
- 마우스 클릭을 지원한다.
- 방향키와 Tab/Shift+Tab으로 이동할 수 있다.
- Enter 또는 Space로 선택하거나 게임을 시작할 수 있다.
- 선택 시간 제한이 없다.

## Editor 생성 메뉴

`Project-Limitless/Milestone 01/Generate Character Creation Scene`은 다음 항목만 갱신한다.

- `CharacterCreation.unity`
- Bootstrap의 시작 Scene 설정
- Build Settings의 Scene 순서

기존 `World_StarterVillage` Scene은 재생성하지 않는다.
