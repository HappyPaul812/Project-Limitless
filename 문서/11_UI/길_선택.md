# Character Creation 2단계 길 선택

## 흐름

`Bootstrap → CharacterCreation → PathSelection → JobSelection` 순서로 진행한다. 이전 버튼으로 돌아가도 이름, Male/Female 외형, 선택한 길 ID를 `GameSessionData`가 유지한다. 길을 선택한 뒤 다음 버튼을 누르면 JobSelection으로 이동한다.

## 데이터 구조

`PlayerPathDefinition` ScriptableObject가 안정적인 ID, 표시 이름, 모티브, 설명, 전투 패시브, 키워드, 추천 직업 ID·표시 이름, 아이콘, 직업 연계 정보를 보관한다. 길의 직접 능력치 보너스는 사용하지 않는다. 에셋은 `Assets/_Project/Resources/PathDefinitions`에 있으며 새 에셋을 추가하면 UI가 자동으로 목록을 확장한다.

선택값은 에셋 참조가 아니라 `GameSessionData.SelectedPlayerPathId` 문자열로 보관한다. 이 값은 Scene 이동 후에도 유지되고 향후 저장 시스템에도 그대로 사용할 수 있다.

## UI

- 왼쪽: 이름, Male/Female, 캐릭터 미리보기
- 중앙: 데이터에서 생성한 길 선택 목록
- 오른쪽: 이름, 한 줄 설명, 직접 능력치 보너스 없음 안내, 패시브, 키워드, 추천 직업 상세 패널
- 상단: `1 기본 정보 / 2 길 / 3 직업 / 4 확인`, 현재 2단계 강조
- 하단: 이전, 다음, 키보드 안내

1280×720 기준으로 상단 안내, 중앙의 가로 5개 카드, 하단 상세 패널과 `이 길을 선택` 버튼을 배치한다. 카드에는 공식 아이콘 슬롯, 길 이름, 특성 이름, 한 줄 추천, 선택 체크를 표시하고 긴 설명은 상세 패널에만 둔다. 상세에는 큰 공식 아이콘, 이름, 특성, 실제 설명, 추천과 비강제 안내를 표시한다.

공식 아이콘은 `PathPresentationResolver`가 `PlayerPathDefinition.Icon`에서 찾는다. 각 화면에 별도 경로 switch를 만들지 않으므로 향후 Sprite 연결이나 새 길 추가가 모든 UI에 같은 상징으로 반영된다. 현재 Heart Shield, Sound Waves, Eye Target, Cog, Mesh Network 파일은 저장소에 없으며 카드에는 `아이콘 준비 중`을 표시한다. 의미가 다른 Kenney target·heart 등의 임시 아이콘은 사용하지 않는다.

## 접근성

마우스, Tab, Shift+Tab, 방향키, Enter, Space를 지원한다. 선택 상태는 배경색뿐 아니라 굵은 테두리와 `✓ 선택됨` 텍스트로, Focus는 더 두꺼운 밝은 테두리로 표시한다. 시간 제한은 없다.

현재 수치와 패시브는 **1차 프로토타입 밸런스**이며 전투 테스트에 따라 변경할 수 있다.

선택한 길의 외형 Preview와 Symbol을 상세/캐릭터 영역에 함께 표시한다. 실제 Sprite가 아직 없는 경우 기존 캐릭터를 보존하며, 외형 데이터 구조는 `길별_캐릭터_외형.md`를 따른다.

## 길과 직업, 추천의 역할

- 길: 고유 전투 패시브, 캐릭터 정체성
- 직업: 전투 역할, 액티브 스킬, 직업 성장
- 추천 직업: 길의 행동 특성과 비교적 잘 맞는 조합을 안내하며 선택을 제한하지 않음

현재 추천 조합은 마음의 상처 `치유사·투사`, 청각의 길 `사수·마도사`, 시각의 길 `투사·사수`, 지체의 길 `마도사·수호자`, 지적의 길 `수호자·치유사`이다. 추천 이유는 각각 위기 회복·반격, 잔향 대상 선택, 단일 공격 연계, 전열 방어·후열 공격, 집중 공격 보호·치유 시너지다. 추천은 초보자 안내이며 선택 제한이 아니므로 모든 5×5의 25가지 조합이 유효하다.
