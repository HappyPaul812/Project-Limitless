# Character Creation 2단계 길 선택

## 흐름

`Bootstrap → CharacterCreation → PathSelection` 순서로 진행한다. 이전 버튼으로 돌아가도 이름, Male/Female 외형, 선택한 길 ID를 `GameSessionData`가 유지한다. JobSelection은 아직 없으므로 다음 버튼은 기존 개발 안내를 표시한다.

## 데이터 구조

`PlayerPathDefinition` ScriptableObject가 안정적인 ID, 표시 이름, 모티브, 설명, 능력치 보너스, 패시브, 키워드, 아이콘, 향후 직업 연계 정보를 보관한다. 에셋은 `Assets/_Project/Resources/PathDefinitions`에 있으며 새 에셋을 추가하면 UI가 자동으로 목록을 확장한다.

선택값은 에셋 참조가 아니라 `GameSessionData.SelectedPlayerPathId` 문자열로 보관한다. 이 값은 Scene 이동 후에도 유지되고 향후 저장 시스템에도 그대로 사용할 수 있다.

## UI

- 왼쪽: 이름, Male/Female, 캐릭터 미리보기
- 중앙: 데이터에서 생성한 길 선택 목록
- 오른쪽: 이름, 한 줄 설명, 적용 후 6종 능력치, 패시브, 키워드 상세 패널
- 상단: `1 기본 정보 / 2 길 / 3 직업 / 4 확인`, 현재 2단계 강조
- 하단: 이전, 다음, 키보드 안내

1280×720 기준으로 5개 항목을 세로 목록에 배치한다. 추가 길도 같은 목록 규칙을 따르며 현재 코드는 길 수를 5개로 고정하지 않는다.

## 접근성

마우스, Tab, Shift+Tab, 방향키, Enter, Space를 지원한다. 선택 상태는 배경색뿐 아니라 굵은 테두리와 `✓ 선택됨` 텍스트로, Focus는 더 두꺼운 밝은 테두리로 표시한다. 시간 제한은 없다.

현재 수치와 패시브는 **1차 프로토타입 밸런스**이며 전투 테스트에 따라 변경할 수 있다.
