# Character Creation 2단계 길 선택

## 목적

기본 캐릭터 정보와 이후 직업 선택 사이에 확장 가능한 Path 선택 단계를 둔다. 한 화면에 모든 결정을 몰아넣지 않고 단계별로 충분한 입력 시간을 제공한다.

이번 Prototype은 실제 세계관의 길 이름, 효과, 직업 연결을 확정하지 않는다. `Path01`~`Path04`는 UI 흐름을 검증하기 위한 임시 슬롯이며 실제 Path 수가 4개라는 뜻이 아니다.

## 현재 흐름

`Bootstrap → CharacterCreation → PathSelection`

- CharacterCreation의 `다음`은 유효한 외형과 이름을 `GameSessionData`에 저장하고 PathSelection을 연다.
- PathSelection의 `이전`은 CharacterCreation을 다시 연다. Bootstrap을 거치지 않으므로 외형, 이름, Path 선택이 유지된다.
- PathSelection의 `다음`은 아직 JobSelection Scene을 열지 않고 개발 단계 안내를 표시한다.
- 최종 목표 흐름은 `Bootstrap → 기본 정보 → 길 → 직업 → 확인 → World_StarterVillage`이다.

## 데이터 구조

`PlayerPathType`은 현재 `None`, `Path01`, `Path02`, `Path03`, `Path04` 개발용 값만 제공한다. `PlayerPathDefinition`은 표시 이름, 아이콘, 한 줄 설명, 상세 설명, 특징, 관련 직업 정보 필드를 UI 선택 로직과 분리한다.

Path 카드는 정의 배열을 순회해 두 열 Grid로 만든다. 향후 항목을 추가하거나 삭제할 때 카드별 if/else를 늘리지 않고 데이터 배열을 바꾸는 구조다.

`GameSessionData.SelectedPlayerPath`는 Scene이 바뀌어도 선택값을 유지한다. 영구 저장 기능은 아니며 Bootstrap으로 새 흐름을 시작하면 `None`으로 초기화된다.

## UI와 접근성

- CharacterCreation과 같은 짙은 남색, 금색 포인트, 중앙 패널 스타일을 사용한다.
- 왼쪽 요약 패널에 PlayerName, Male/Female 문구, Down Idle Sprite를 표시한다.
- 오른쪽에 임시 Path 카드 4개를 2×2로 표시한다.
- 선택 카드는 굵은 금색 테두리, `✓ 선택됨` 문구, 밝아진 배경을 함께 사용한다.
- `1 기본 정보 / 2 길 / 3 직업 / 4 확인` 중 `2 길 · 현재`를 텍스트와 테두리로 강조한다.
- 마우스, Tab, Shift+Tab, 방향키, Enter, Space를 지원하며 시간 제한이 없다.
