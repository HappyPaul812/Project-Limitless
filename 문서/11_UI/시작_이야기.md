# 시작 이야기

## 흐름

빈 저장 슬롯의 새 캐릭터는 `OpeningIntro`를 거쳐 `CharacterCreation`으로 이동한다. `SkipOpeningIntro`가 켜져 있으면 바로 CharacterCreation으로 이동하며 기존 캐릭터 이어하기는 저장된 월드로 복귀한다. Bootstrap의 `시작 이야기 다시 보기`는 설정과 무관하게 재생하고 완료·건너뛰기 뒤 Bootstrap으로 돌아간다.

## 표시와 입력

`OpeningIntroSequence` 한 곳에서 1차 확정 서사, 표시 시간과 Light·Stillness·Paths·Title 같은 연출 종류를 관리한다. 검은 배경, 추상적인 빛, 반투명 자막 배경, Fade와 느린 확대를 사용하며 전용 일러스트 없이도 완주할 수 있다. 추상 빛은 런타임에 생성한 방사형 알파 Sprite의 바깥 빛과 중심 빛을 겹쳐 사용한다. 가장자리 알파를 0으로 만들어 UI Image의 사각형 경계가 드러나지 않으며, 자막보다 뒤에서 같은 CanvasGroup Fade를 적용받는다. 자막은 화면 위 기준 약 69% 지점에 두고, 실제 문장 크기에 좌우 42px·상하 20px 여백만 더한 어두운 방사형 배경으로 감싼다. 연결 장면은 `PathPresentationResolver`가 제공하는 자체 제작 PathSymbol 5개를 마음의 상처·청각·시각·지체·지적 순서로 표시한다. Game-icons.net TraitIcon은 사용하지 않는다.

- 자동 진행: 각 문장의 데이터 시간 뒤 진행
- 수동 진행: 화면 클릭, Enter 또는 Space
- 일시정지/재개: P
- 이번 한 번 건너뛰기: Esc 또는 `건너뛰기` 버튼
- 이후 새 게임 자동 건너뛰기: `다음부터 시작 이야기를 자동으로 건너뜁니다.` 체크

Esc와 건너뛰기 버튼은 전역 설정을 바꾸지 않는다. 체크박스만 `UserSettingsService`를 통해 설정을 저장한다. 모든 서사는 한글 자막으로 제공하고 아이콘에는 Path 이름을 함께 사용한다. 마지막 플레이어 표시명은 `LIMITLESS`다.

## 내레이션

확정된 MeloTTS 한국어 음질 기준인 speaker `KR`, speed `1.00`으로 첫 18개 문장을 미리 생성해 `Assets/_Project/Audio/Voice/Opening`에 둔다. 마지막 `LIMITLESS`는 제목을 보여 주는 장면이므로 음성을 붙이지 않는다. 자막은 음성 사용 여부와 관계없이 항상 표시한다.

`OpeningIntroSequence`의 `VoiceClipId`와 `OpeningNarrationCatalog`의 직접 `AudioClip` 참조가 문장과 파일을 연결한다. 런타임은 MeloTTS, Python, 모델 파일을 포함하거나 실행하지 않는다. Clip이 기존 문장 표시 시간보다 길면 `Clip 길이 + 0.5초`까지 장면을 유지하고, 짧으면 기존 시간을 유지한다. 클릭·Enter·Space로 진행하거나 Esc·건너뛰기 버튼으로 끝낼 때 현재 음성을 즉시 멈춘다. P 일시정지는 재생 위치를 보존하고 재개하며, 다시 보기에서도 처음부터 같은 음성을 재생한다. 자동 건너뛰기 설정으로 인트로 Scene에 들어오지 않으면 음성도 재생되지 않는다.

## 전역 설정

`SkipOpeningIntro`는 캐릭터 슬롯과 무관한 `UserSettingsData`다. Editor에서는 `Unity/Client/UserData/Settings/user_settings.json`, 빌드에서는 `Application.persistentDataPath/Settings/user_settings.json`에 저장한다. 파일이 없거나 손상됐거나 버전이 맞지 않으면 `false`를 사용하고, 쓰기 실패는 경고만 남겨 게임 시작을 막지 않는다.

## 개발 확인

Unity 메뉴 `Project Limitless/Test/Play Opening Intro`는 다시 보기 모드로 Scene을 열어 저장 슬롯을 만들지 않는다. 실제 플레이 흐름과 UI 배치는 Play Mode에서 별도로 확인한다. 특히 Light·Gift·Limit 장면에서 검은 배경과 광원 사이에 사각형 경계가 없고, 중심은 밝고 가장자리는 자연스럽게 투명해지는지 확인한다. 자막 배경이 문장 주변에만 머물러 광원을 가로로 자르지 않고, Paths 장면의 Symbol 및 하단 조작 UI와 겹치지 않아야 한다. 광원이 서서히 나타나 약하게 퍼졌다가 사라지는 동안 자막 대비와 `LIMITLESS` 표시가 유지되어야 한다. 내레이션은 문장과 일치하는지, 자동 진행에서 잘리지 않는지, 수동 진행·P·Esc·다시 보기·자동 건너뛰기에서 위 동작 규칙을 지키는지도 확인한다.
