# Character Creation 3단계 직업 선택

## 흐름

`Bootstrap → CharacterCreation → PathSelection → JobSelection → FinalConfirmation`으로 진행한다. JobSelection의 이전 버튼은 PathSelection으로 돌아가며 이름, 외형, 길, 이전에 선택한 직업 ID를 유지한다. 직업을 선택한 뒤 다음 버튼을 누르면 최종 확인 화면으로 이동한다.

## 역할과 데이터

- 길: 기본 능력 성향, 고유 패시브, 캐릭터 정체성
- 직업: 전투 역할, 향후 액티브 스킬, 향후 직업 성장
- 추천: 선택한 길과 어울리는 직업 안내이며 선택 제한이 아님

`JobDefinition` ScriptableObject는 안정적인 JobId, 표시 이름, 역할, 설명, 주 능력치, 전투 키워드, 총 +4 능력치 보너스, 고유 패시브, 시작 스킬 3개의 프리뷰 데이터를 보관한다. 현재 직업은 수호자, 치유사, 사수, 투사, 마도사다. 프리뷰는 실제 전투 실행 로직과 분리하며 미확정 수치는 전투 테스트 후 결정한다.

## 추천 연계

JobSelection은 `SelectedPlayerPathId`로 PathDefinition을 찾고 기존 `RecommendedJobs`의 직업 ID를 읽어 카드에 `추천` 텍스트를 표시한다. 추천 여부와 버튼 활성화는 분리되어 모든 5×5 조합을 선택할 수 있다.

## UI와 접근성

왼쪽에 캐릭터 이름·외형·선택한 길, 중앙에 5개 직업 카드, 오른쪽에 역할·설명·주 능력치·전투 성향·능력치 보너스·패시브 요약·시작 스킬 이름·길+직업 최종 능력치·추천 여부를 표시한다. 선택은 굵은 금색 테두리와 `✓ 선택됨`, 추천은 별도 `추천` 텍스트, Focus는 더 밝고 굵은 테두리로 구분한다. 마우스, Tab, Shift+Tab, 방향키, Enter, Space를 지원한다.
